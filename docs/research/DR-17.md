# Zero-Annotation Interprocedural Call-Graph Effect and Capability Inference, Supply-Chain Lockfile Sandboxing, and @no_alloc / @no_panic Verification for CoreX (.cx)

CoreX (`corex-lang/corex`) enforces compile-time per-package OS/FFI capability sandboxing and hard real-time `@no_alloc` / `@no_panic` safety contracts – with **zero permission annotations in ordinary `.cx` code** and **zero `--release` runtime instructions** – by piggybacking a 16-bit **`EffectCapabilityMask`** (`fs`, `net`, `env`, `process`, `ffi`, `unsafe_op`, `alloc`, `may_panic`, `clock`, `entropy`, `blocking_sync`, `indirect_opaque`) onto Phase 6's Tarjan Strongly Connected Component (SCC) bottom-up `MIR` summary pass (`DR-06` Pass 3). Packed alongside `DR-06`'s escape/provenance bitmasks and `DR-20`'s stack-budget (`D-02`) and scratch-arena (`D-04`) fields, the extended **`FnRegionSummary`** forms an exact, zero-padding **40-byte** record stored in Struct-of-Arrays (`MultiArrayList` / `#soa`) columns. Under layout and throughput calculations on `DR-12`'s modeled 500,000-line workspace (`1,250` files, `25,000` functions, and `87,500` call edges), the hot `inferred_effects` column occupies **48.83 KiB** in L1d/L2 cache, the complete summary table occupies **976.56 KiB**, and the Compressed Sparse Row (CSR) witness call graph occupies **1.10 MiB** – adding **1.48 MiB** of net workspace memory while keeping single-keystroke `corex lsp` incremental turnaround at a modeled **432 µs (0.432 ms)** via `CompilerDb` 128-bit Early Cutoff.

This unified `MIR` pass delivers two verification capabilities across Phases 6, 9, and 10 without requiring effect-polymorphic boilerplate. First, **Compile-Time Supply-Chain Capability Sandboxing** builds on CoreX's elimination of arbitrary `build.rs` scripts, host-executing procedural macros, and pre-`main` constructors to infer the OS and FFI authority transitively reachable from every package in `corex.lock` and `.cxi` (`DR-20` `D-08`). Hardened per `DR-20` `Fix-17` – hermetic zero-syscall `MirVm` `comptime`, OS-kernel symlink-jailed `@embed_bytes` (`openat2` `RESOLVE_BENEATH | RESOLVE_NO_SYMLINKS` on Linux, `O_NOFOLLOW_ANY` on macOS, `O_RESOLVE_BENEATH` on FreeBSD, and `FILE_FLAG_OPEN_REPARSE_POINT` reparse/junction rejection on Windows), unconditional `ffi | unsafe_op` ambient tainting on `extern`/`@export`/`@link_name`/`@link_section`/`asm`, and coercion-site callback/vtable reification tracking – `corex build` and `corex upgrade` halt compilation (`E0324`) before codegen if a patch update to a pure library silently introduces `std::net`, `std::process`, or `ffi`.

Second, **Optimization-Independent `@no_alloc` and `@no_panic` Verification** checks contracts directly on post-Pentagon Block-Argument SSA `MIR` (`DR-06` Pass 4 with `DR-20` `Fix-06A` demand slicing capped at `MAX_SUB_VARS = 256`), producing identical verification results at `-O0` and `-O3` rather than relying on fragile backend dead-code elimination. `@no_alloc` rejects dynamic `context.allocator`, `SystemAllocator`, and growable slab allocations while allowing fixed stack buffers, `FixedArena` slice bumps, non-growing `FixedSlabPool` freelists, and conflict-verified `Context.scratch[0..2]` checkpoints (`D-04`), while a companion `blocking_sync` bit (`@no_block`) catches allocator `free()` lock contention and blocking syscalls. `@no_panic` provides SPARK Silver-style Absence of Run-Time Errors (AoRTE) coverage on `MIR` across slice/array bounds, division/remainder by zero, signed `INT_MIN / -1` overflow, checked arithmetic, `.unwrap()`/`panic` terminators, and MVS `inout` `subscript`/`yield` non-`Copy` projection guards (`DR-20` `Fix-06B`) – complemented by `@max_stack(N)` (`D-02`) to bound stack storage exhaustion – and reconstructs minimal-hop witness call chains (`fn A ▸ fn B ▸ leaf trap`) via lazy `O(V_R + E_R)` breadth-first search on failure.

## 1. Landscape Synthesis and Architectural Rationale

Existing ecosystems retrofit supply-chain capability auditing and real-time allocation/panic contracts through external whole-program analyzers, process-wide runtime flags, or annotation-heavy type systems, each carrying structural trade-offs resolved by CoreX's `MIR` architecture:

| Toolchain / System | Enforcement Granularity & Mechanism | Documented Strengths | Structural Gaps Closed by CoreX (`DR-17`) |
| :--- | :--- | :--- | :--- |

| **`Cackle` (`cargo acl`)** (Rust) | Wraps `rustc`/linker; parses ELF object relocations and DWARF debug info against `cackle.toml`. | Dead-code aware on linked binaries; generates static backtraces from `main`. | Linux-only (misses Windows/macOS-gated payloads); `allow_unsafe = true` permits raw `asm` syscalls; coarse shared `rustc` proc-macro sandbox; requires DWARF debug tables. |

| **Scala 3 Capture Checking & Koka** | Capture sets (`T^{c}`) / Hindley-Milner row-polymorphic effect variables (`<alloc, exn \| e>`). | Implicit capability polymorphism on higher-order `map`/`foreach` callbacks. | Complex subtyping/unification Diagnostics on escaping containers; designed around GC or Perceus reference counting. |

| **Rust `no-panic` / `jonesy` & SPARK AoRTE** | `no-panic`: undefined linker symbol inside drop guard relying on DCE. | **CoreX (`DR-17`)** | **Phase 6 Tarjan SCC `EffectCapabilityMask` + Demand-Sliced Pentagon `MIR` + `corex.lock` / `.cxi` Policy.** | **Zero annotations in ordinary code; `-O0 === -O3` parity; per-package compile-time sandboxing; `< 0.5 ms` modeled LSP.** | Soundness is modulo audited `core`/`std` boundary wrappers; stored/escaping function pointers invoked in `@no_alloc`/`@no_panic` scopes require explicit pointer-type modifiers. |

CoreX closes the bypass vectors observed in `Cackle`, `Capslock`, and Deno because four structural invariants are already established across `DR-01` through `DR-20`. Package builds forbid arbitrary `build.rs` hooks and host-side procedural macros (`DR-11`), executing all `comptime` and `@derive` logic inside the deterministic, fuel-bounded `MirVm` virtual machine (`DR-20`). Pre-`main` global constructors are banned by the language specification (`DR-11`), and `Fix-17` blocks user placement into OS loader initialization or TLS-callback sections. Dynamic memory and host OS interactions flow exclusively through explicit `Context` handles (`context.allocator`, `Context.scratch[0..2]`, `Context.reactor`, `Context.rng`) and audited `core::sys` / `std::sys` leaf modules (`DR-06`, `DR-20`). Finally, Phase 6 already traverses the `MIR` call graph bottom-up in Tarjan `O(V + E)` SCC order (Pass 3) and executes demand-sliced Pentagon (`Intv × Sub`) range analysis (Pass 4), allowing `EffectCapabilityMask` inference to ride on existing passes with zero extra call-graph walks.

## 2. Deliverable 1: Formal MIR EffectCapabilityMask, Extended FnRegionSummary Layout, Indirect-Call Rules, and Fix-17 Sandbox Hardening

### 2.1 The 16-Bit EffectCapabilityMask Join-Semilattice

Formally, `EffectCapabilityMask` forms a finite 16-bit bounded join-semilattice $\mathcal{L}_{\text{eff}} = (\{0, 1\}^{16}, \sqsubseteq, \sqcup, \bot)$ where $\bot = \texttt{0x0000}$ denotes a pure, allocation-free, panic-free, non-blocking computation, join $a \sqcup b = a \mathbin{|} b$ is single-cycle bitwise OR, and partial order $a \sqsubseteq b \iff (a \mathbin{\&} \sim b) == 0$ tests whether inferred mask $a$ stays within ceiling $b$:

| Bit | Hex Mask | Identifier | Category | Exact `MIR` / Intrinsic Origin & Semantic Meaning |
| :--- | :--- | :--- | :--- | :--- |
| **`0`** | `0x0001` | **`fs`** | Supply-Chain | Filesystem read, write, stat, directory walk, chmod, unlink, link, or mount (`std::fs::*`). |
| **`1`** | `0x0002` | **`net`** | Supply-Chain | Socket creation, DNS lookup, TCP/UDP/Unix bind/connect/listen, or HTTP/TLS I/O (`std::net::*`, `std::http::*`). |
| **`2`** | `0x0004` | **`env`** | Supply-Chain | Reading or mutating environment variables, working directory, `argv`, PID, or OS host/user metadata (`std::env::*`). |
| **`3`** | `0x0008` | **`process`** | Supply-Chain | Spawning child processes (`exec`/`CreateProcess`), killing processes, signal disposition, or abnormal exit (`std::process::*`). |
| **`4`** | `0x0010` | **`ffi`** | Supply-Chain | Declaring/calling `extern` functions or statics, `@export`, `@link_name`, `@link_section`, or `asm`. |
| **`5`** | `0x0020` | **`unsafe_op`** | Supply-Chain | Raw pointer dereference (`*p`), pointer offset (`p.add`), mutable `static` access, `union` field read, unchecked cast, or `asm`. |
| **`6`** | `0x0040` | **`alloc`** | Safety / RT | Dynamic heap or backing-slab allocation/growth (`context.allocator`, `SystemAllocator`, growable `Arena`/`Vec`/`String`/`Map`). |
| **`7`** | `0x0080` | **`may_panic`** | Safety / RT | Residual un-elided `MIR` trap edge after Pass 4 Pentagon BCE/VRP (bounds, div-zero, overflow, `.unwrap()`, `panic`, `yield` guard). |
| **`8`** | `0x0100` | **`clock`** | Determinism | Direct host wall/monotonic clock syscalls bypassing `Context.reactor.monotonic_ns` (`DR-20` Seam #5 / `--sim` determinism). |
| **`9`** | `0x0200` | **`entropy`** | Determinism | Direct host OS CSPRNG syscalls (`getrandom` / `BCryptGenRandom`) bypassing `Context.rng` (`DR-20` `Fix-18A`). |
| **`10`** | `0x0400` | **`blocking_sync`** | Safety / RT | OS mutex/futex lock acquisition, thread sleep, `SystemAllocator::free` lock path, or synchronous blocking syscall (`@no_block`). |
| **`11`** | `0x0800` | **`indirect_opaque`** | Call-Graph | Unconstrained dynamic `fn(…)` or `dyn Trait` call whose type signature lacks `@no_alloc` / `@no_panic` / `@no_block` bounds. |
| **`12..15`** | `0xF000` | `_reserved` | Reserved | Zero-initialized (`0`) across all `BumpArena` slabs and `.cxi` binary records for future `0.x` effect extensions (`DR-01`). |

*(Note on `DR-20` Seam #2 `Context.trace_sink`: Recording a `@trace_span` event into the pre-allocated lock-free `Context.trace_sink` ring buffer using `Context`'s virtual/monotonic clock carries `EffectCapabilityMask = PURE (0x0000)` so structured `FlightRecorder` instrumentation never invalidates `@no_alloc`, `@no_panic`, or `@no_block` contracts or taints pure packages with `clock`.)*

#### The Trusted Standard-Library Safe-Wrapper Boundary

A recurring failure mode in naive IR capability trackers is **internal `std` implementation leakage**: `std::col::Vec::push` internally executes `unsafe { self.ptr.add(self.len).write(val) }` to initialize spare capacity, and `std::fs::File::open` invokes `extern "C"` OS syscalls. If internal `unsafe_op` and `ffi` bits propagated unfiltered out of audited `core` and `std` containers, every pure library using `Vec[T]` or `String` would appear in `corex.lock` as requiring `unsafe`, recreating `Cackle`'s `allow_unsafe = true` over-granting problem.

Adapting Austral's `Unsafe_Module` capability encapsulation and `Capslock`'s `CAPABILITY_SAFE` termination boundary, CoreX restricts the internal compiler attribute `@std_cap_boundary(emits = Mask, clears = Mask)` strictly to source files mounted under `PackageId.std_lib == 1` (`core` and `std`) in `VfsSourceMap` (`DR-11` §2.4). Any use of `@std_cap_boundary` in workspace (`PackageId == 0`) or external dependency (`PackageId >= 2`) code is rejected immediately with hard error **`E0327`**. For an audited `std` wrapper $w$, Pass 3 transforms its outgoing summary mask via:

$$\mathcal{E}_{\text{summary}}(w) = \big((\mathcal{E}_{\text{body}}(w) \mathbin{\&} \sim\text{clears}) \mathbin{|} \text{emits}\big)$$

Under this rule, `std::col::Vec::push` clears its internal memory-safe `unsafe_op` write and emits `alloc | may_panic | blocking_sync`; `std::col::Vec::try_push` clears `unsafe_op` and emits `alloc | blocking_sync` (`may_panic = 0`); and `std::fs::File::open` clears its internal `ffi | unsafe_op` syscall shim and emits `fs | blocking_sync`. Because third-party packages (`PackageId >= 2`) cannot declare `@std_cap_boundary`, any `unsafe { … }` block, raw pointer dereference, `extern` symbol, or inline `asm` in an external dependency permanently sets `unsafe_op` and/or `ffi` in that package's `EffectCapabilityMask`.

### 2.2 Extended 40-Byte FnRegionSummary Layout and CompilerDb Early Cutoff

To unify `DR-06` Pass 3 (`24 bytes`), `DR-20` `D-02` stack and `async` coroutine frame budgets (`+8 bytes`), `DR-20` `D-04` 2-slot `Context.scratch[0..2]` ping-pong exclusivity, and `DR-17` capability/contract tracking (`+8 bytes`), CoreX defines a **40-byte (`320-bit`), 8-byte-aligned, zero-padding `FnRegionSummary`**:

| Byte Offset | Field Name | Type | Size | Subsystem Origin & Role |
| :--- | :--- | :--- | :--- | :--- |
| `0..8` | `ret_provenance_mask` | `u64` | `8 B` | **`DR-06` Pass 3:** Input parameter, static, or `Context` regions aliased by the return value. |
| `8..16` | `param_flow_matrix` | `u64` | `8 B` | **`DR-06` Pass 3:** `8x8` bit matrix where bit `(src * 8 + dst)` marks cross-parameter region stores. |
| `16..20` | `global_escape_mask` | `u32` | `4 B` | **`DR-06` Pass 3:** Parameters whose addresses escape to globals or detached threads. |
| `20..24` | `consumed_param_mask` | `u32` | `4 B` | **`DR-06` Pass 3:** `@linear` parameters consumed (`own` / `sink`) along all non-diverging returns. |
| `24..28` | `own_frame_bytes` | `u32` | `4 B` | **`DR-20` `D-02`:** Local stack frame size (or unioned `async` suspend-point state frame). |
| `28..32` | `max_subtree_bytes` | `u32` | `4 B` | **`DR-20` `D-02`:** Worst-case transitive call-subtree stack bytes (`0xFFFF_FFFF` on SCC cycle). |
| `32..34` | `inferred_effects` | `EffectCapabilityMask` | `2 B` | **`DR-17` Pass 3:** Transitive fixed-point effect and capability bitmask across all callees. |
| `34..36` | `direct_effects` | `EffectCapabilityMask` | `2 B` | **`DR-17` Pass 4:** Intraprocedural post-Pentagon local EffectCapabilityMask (terminates witness BFS in `O(1)`). |
| `36..38` | `contracts_scratch` | `FnContractScratchMask` | `2 B` | **`DR-17` + `DR-20` `D-04`:** Explicit `@no_alloc`/`@no_panic` contracts + 4-bit `Context.scratch[0..2]` effect. |
| `38..40` | `forwarded_cb_mask` | `u16` | `2 B` | **`DR-17` Pass 3:** Bit `i` (`0..15`) = `1` iff non-escaping callable parameter `i` is invoked synchronously. |

#### Preserving Sub-Millisecond CompilerDb Early Cutoff

In `DR-12` §3.1–3.3, editing inside a function body hits the `item_tree(FileId).sig_hash` firewall so only the single edited `DefId` re-runs `typecheck_body` (`85 µs` modeled) and `verify_sast_mir` (`65 µs` modeled). Naively coupling interprocedural `FnRegionSummary` inference (`Pass 3`) to raw callee `MIR` bodies would invalidate transitive callers on every keystroke. CoreX preserves `CompilerDb` Early Cutoff (`executeAndBackdate` via `Fingerprint128`) by splitting `verify_sast_mir` (`query_db.zig` Stage 9, updating `STAGE_COUNT` and maintaining a dense `DefId <-> DefIndex` table) into three fine-grained query stages. First, `QueryStage.sast_local_body(DefId)` executes intraprocedural Pass 1 (`MovePath` trie), Pass 2 (`DenseBitSet` initialization, `AutoDrop` elaboration, and Ghost exclusivity), and Pass 4 (demand-sliced Pentagon BCE/VRP). Because Pass 4 reads only `typecheck_body(DefId)` and `def_signature(CalleeDefId)` – never callee `MIR` bodies – it computes `direct_effects` (recording unconstrained `indirect_fn_ptr` / `indirect_vtable` ceiling bits strictly on `csr_edges` with `callee_def = .none` and in `inferred_effects`, rather than in `direct_effects`, so shortest-witness BFS walks `csr_edges` to pinpoint exact indirect call sites), `own_frame_bytes`, `forwarded_cb_mask`, and local `WitnessCallEdge` records purely locally.

Second, `QueryStage.fn_region_summary(DefId)` evaluates the Tarjan SCC fixed point over `sast_local_body(DefId)` and `fn_region_summary(CalleeDefId)`, but computes its `MemoHeader.output_fingerprint: Fingerprint128` strictly over the **34-byte Caller-Observable Summary Projection** – excluding `direct_effects` (`2 B`) and `own_frame_bytes` (`4 B`, as callers depend only on `max_subtree_bytes`). Whenever an in-body edit leaves a function's net transitive `inferred_effects`, `max_subtree_bytes`, and region provenance unchanged, `Fingerprint128.eql(old_fp, new_fp)` holds, `memo.changed_at` remains backdated, and zero callers re-execute (`10 µs` modeled verification check, yielding **432 µs** total single-keystroke LSP turnaround). Third, when a function `g` carries explicit `@no_alloc`, `@no_panic`, or `@no_block` attributes, `fn_region_summary(g)` clamps its exported `inferred_effects` by clearing `alloc`, `may_panic`, and/or `blocking_sync` even if `g`'s body currently has a mid-keystroke violation: `QueryStage.verify_sast_contracts(g)` reports `E0320`, `E0321`, or `E0322` locally on `g` while insulating callers from cascading secondary errors during interactive editing.

### 2.3 Sound Indirect-Call Propagation Without Verbose Effect Polymorphism

To propagate `EffectCapabilityMask` across higher-order callbacks, first-class function pointers (`fn(…)`), `@local` / `own` closures, and `dyn Trait` vtables without imposing Koka-style row-polymorphic effect variables (`forall <e>`) on everyday `.cx` code, CoreX combines **Higher-Order Callback Forwarding** with a **Reification-vs.-Invocation Split**.

Under **Rule 1 (Zero-Annotation Higher-Order Forwarding for `@local` Closures and Generic Callables)**, standard closures in CoreX (`arr.sort_by(|a, b| a.id.cmp(&b.id))`, `slice.iter().for_each(|x| …)`) are non-escaping second-class `@local` values (`DR-06` §1.3). During `sast_local_body(f)`, if parameter `p_i` (`0 ≤ i < 16`) is a `@local` closure or generic callable invoked inside `f` (or forwarded as argument `j` to a callee `h` whose `h.forwarded_cb_mask` has bit `j` set) that does not escape (`(global_escape_mask & (1 << i)) == 0`, row `i` of `param_flow_matrix == 0`, and `(ret_provenance_mask & (1 << i)) == 0`), Pass 3 leaves `indirect_opaque = 0` on `f` and sets bit `i` in `f.forwarded_cb_mask` (falling back conservatively to `UNCONSTRAINED_INDIRECT` for callable parameters at index `i ≥ 16`). At any call site `f(arg_0, …, arg_{k-1})` inside caller `u`, Pass 3 instantiates the call-site effect in `O(1)` bitwise arithmetic:

$$\mathcal{E}_{\text{site}}(u \to f) = f.\text{inferred\_effects} \;\mathbin{|}\; \big|_{i:\, (f.\text{forwarded\_cb\_mask} \gg i) \& 1 = 1} \mathcal{E}(\text{arg}_i)$$

Consequently, `std::slice::sort_by` is written once with zero `@no_alloc`, `@no_panic`, or effect-generic annotations (`inferred_effects = 0x0000`, `forwarded_cb_mask = 0b0010`). Calling `sort_by` inside a `@no_alloc @no_panic` interrupt handler with `|a, b| a < b` yields `0 | 0 = 0` (passing verification), whereas calling `sort_by` with a closure that writes to a file and allocates strings propagates `fs | alloc | may_panic | blocking_sync` strictly to the caller `u`.

Under **Rule 2 (First-Class Escaping Function Pointers and `own` Closures)**, storing a function pointer or `own` closure in a `struct`, collection, or return value erases its concrete target at the call site. CoreX cleanly separates supply-chain authority tracking from real-time contract subtyping:

1.  **Coercion-Site Supply-Chain Reification (`MirOp.fn_addr` and `MirOp.vtable_ref`):** Whenever function `u` in package `P` takes the address of function `g` (`let fp: fn() = g;`), packs an escaping `own` closure, or coerces a concrete type into `&dyn Trait`, Pass 3 emits a `reify_fn_addr` (or `reify_vtable`) edge from `u` to `g` (and to each `impl` method of that `(ConcreteType, Trait)` pair), propagating `g.inferred_effects & LOCKFILE_CAP_BITS` (`0x033F`: `fs | net | env | process | ffi | unsafe_op | clock | entropy`) into `u.inferred_effects`. Even if a compromised pure library never calls `exfil()` itself – instead hiding `exfil` inside an exported callback or error-formatting vtable for `main` to invoke later (closing the `exec.wrappedError` interface-laundering pattern noted in `Capslock`) – referencing `exfil` immediately taints the library's `EffectCapabilityMask` and triggers `E0324`. Simultaneously, excluding `alloc` and `may_panic` from `LOCKFILE_CAP_BITS` on address-taking lets `@no_alloc` setup routines register pointers to allocating shutdown handlers without false positives.
2.  **Covariant Function-Pointer Subtyping (`P4312R0` / Clang FEA Model):** First-class function pointer types carry a 3-bit `FnPtrContractMask` (`has_no_alloc`, `has_no_panic`, `has_no_block`) in `InternPool` (`DR-04`), making contract guarantees part of formal type identity so they cannot be stripped across generic containers:

| Surface Function-Pointer / `Trait` Type | `FnPtrContractMask` | Invocation Ceiling $\mathcal{C}(\tau_{\text{fn}})$ | Implicit Covariant Upcast Targets Allowed ($\mathcal{C}_{\text{src}} \sqsubseteq \mathcal{C}_{\text{dst}}$) |
| :--- | :--- | :--- | :--- |
| `fn(A) -> B` / `own fn(A) -> B` | `0b000` | `alloc \| may_panic \| blocking_sync \| indirect_opaque` (`0x0CC0`) | `fn(A) -> B` only (cannot convert to `@no_alloc` or `@no_panic`). |
| `@no_alloc fn(A) -> B` | `0b001` | `may_panic \| blocking_sync \| indirect_opaque` (`0x0C80`) | `@no_alloc fn(A) -> B`, `fn(A) -> B`. |
| `@no_panic fn(A) -> B` | `0b010` | `alloc \| blocking_sync \| indirect_opaque` (`0x0C40`) | `@no_panic fn(A) -> B`, `fn(A) -> B`. |
| `@no_alloc @no_panic fn(A) -> B` | `0b011` | `blocking_sync \| indirect_opaque` (`0x0C00`) | `@no_alloc @no_panic fn`, `@no_alloc fn`, `@no_panic fn`, `fn`. |
| `@no_alloc @no_panic @no_block fn(A) -> B` | `0b111` | `0x0000` (`PURE` real-time ceiling) | Convertible to **all** function pointer variants with matching `(A) -> B`. |

Under **Rule 3 (`dyn Trait` Vtable Dispatch and Covariant `impl` Verification)**, `@no_alloc`, `@no_panic`, and `@no_block` attributes on a `trait` method `Trait::m` establish the vtable slot's ceiling $\mathcal{C}(\text{Trait}::m)$. Every `impl Trait for Concrete` is verified in Pass 3 against the covariant override bound $(\mathcal{E}(\text{Concrete}::m) \mathbin{\&} \texttt{CONTRACT\_SAFETY\_BITS}) \sqsubseteq \mathcal{C}(\text{Trait}::m)$; any violation emits **`E0323 (TraitImplEffectEscalation)`** at the `impl` method with the shortest witness trace, ensuring dynamic `&dyn Trait` calls inside `@no_alloc` / `@no_panic` / `@no_block` functions are sound in `O(1)`.

### 2.4 DR-20 Fix-17 Complete Sandbox Hardening Specification

`DR-20` Audit 3.5 (`Fix-17`) identified three declaration-time, build-time, and link-time avenues by which a malicious dependency could execute host operations during compilation or run arbitrary code prior to `main` outside the `MIR` call graph. `DR-17` closes all three unconditionally.

#### Gate A – Hermetic Zero-Syscall MirVm Comptime (`E0325`)

Before Phase 5's `MirVm` evaluates any `const` initializer, array length expression, `comptime { … }` block, or `@derive` expansion rooted at `MirBody` $b_0$, the compiler queries `fn_region_summary(b_0)` and asserts $(b_0.\text{inferred\_effects} \mathbin{\&} \texttt{LOCKFILE\_CAP\_BITS}) == 0$. Virtual `MirVm` arena allocation (`alloc`, bounded at `MAX_COMPTIME_HEAP = 64 MiB` via `E0508`) and `may_panic` (reported as a deterministic compile-time evaluation diagnostic) are permitted, whereas any statically reachable `fs`, `net`, `env`, `process`, `ffi`, `unsafe_op`, `clock`, or `entropy` operation aborts prior to VM execution with **`E0325 (ComptimeSandboxViolation)`** and a shortest-witness call trace (complementing `MirVm`'s dynamic trap `E0503` on indirect/opaque operations). At the VM layer, `MirVm`'s opcode dispatch table binds zero host OS or `libc` I/O symbols and caps execution at `MAX_COMPTIME_FUEL = 10_000_000` instructions (`E0501`).

#### Gate B – Dual CAS and OS-Kernel Symlink-Jailed @embed_bytes (`E0326`)

`@embed_bytes("assets/table.bin")` (`DR-20` `D-03`) lowers binary assets directly to a 24-byte `MirConst::RawBlob(FileId, u64, u64)` descriptor hashed in `CompilerDb` via BLAKE3. To block lexical `..` escapes, Git-committed symlinks pointing outside the package root, NTFS directory junctions, and concurrent TOCTOU symlink swaps (`CVE-2026-68491`), `corex` enforces a three-tier path jail:

| Package Origin (`VfsSourceMap`) | Path-Jailing & Symlink / Reparse-Point Rejection Protocol | Inferred Capability |
| :--- | :--- | :--- |
| **1. Lexical Filter (All Packages)** | Rejects empty strings, NUL bytes, leading `/` or `\`, Windows drive prefixes (`C:`), UNC paths (`\\`), reserved DOS device names, and component stacks underflowing depth `0` via `..` (`E0326`). | `0x0000` (`pure`) |
| **2. External Locked Packages** (`PackageId >= 2` in `corex.lock`) | **Zero Host Filesystem Traversal:** Resolves the normalized POSIX relative path exclusively via `O(log K)` binary search inside `~/.corex/cache/blake3/trees/<tree_blake3>.cxtree` (`DR-11` §2.4). Because `.cxtree` admits only regular file entries (`0x01`, `0x02`) and zero symlinks, locked dependencies cannot address any host file outside their verified BLAKE3 Merkle tree. | `0x0000` (`pure`) |
| **3. Workspace & Local `path` Packages** (`PackageId == 0` or `path+file://`) | Opens strictly beneath pre-opened `pkg_root_dirfd` without following symlinks or reparse points (`E0326` on `ELOOP`, `EXDEV`, or reparse attribute):<br>• **Linux (`>= 5.6`):** `openat2(pkg_root_dirfd, rel, &open_how { .flags = O_RDONLY\|O_CLOEXEC\|O_NOFOLLOW, .resolve = RESOLVE_BENEATH\|RESOLVE_NO_SYMLINKS\|RESOLVE_NO_MAGICLINKS\|RESOLVE_NO_XDEV }, sizeof(open_how))` + `fstat` `S_ISREG` check (per-component `openat(…, O_NOFOLLOW)` fallback on older kernels).<br>• **macOS (`>= 11` XNU):** `openat(pkg_root_dirfd, rel, O_RDONLY\|O_CLOEXEC\|O_NOFOLLOW_ANY)` (`0x20000000`) + `fcntl(fd, F_GETPATH, buf)` canonical prefix check + `S_ISREG`.<br>• **FreeBSD (`>= 13`):** `openat(pkg_root_dirfd, rel, O_RDONLY\|O_CLOEXEC\|O_NOFOLLOW\|O_RESOLVE_BENEATH)` + per-segment symlink rejection.<br>• **Windows (`NTFS`):** Per-segment `CreateFileW` walk from `pkg_root` using `FILE_FLAG_OPEN_REPARSE_POINT`, rejecting `FILE_ATTRIBUTE_REPARSE_POINT` (NTFS symlinks, directory junctions, volume mount points, `IO_REPARSE_TAG_APPEXECLINK`) + `GetFinalPathNameByHandleW` prefix verification + `FILE_TYPE_DISK`. | `0x0000` (`pure` build input tracked in `CompilerDb`) |

#### Gate C – Pre-main Loader Sections, IFUNC, RFC 3325 Symbol Interposition, and Inactive @cfg Pre-Scanning (`E0327`)

In C and Rust supply-chain attacks, backdoors achieve pre-`main` execution by placing function pointers into OS dynamic-loader or TLS callback sections, or hijack standard library routines (such as `write` or `free`) via unmangled global symbols without ever being called from `main`. Outside `PackageId.std_lib` (`core::rt` startup glue), CoreX rejects `@ifunc` / `STT_GNU_IFUNC` resolvers (which execute during dynamic relocation processing before `.init_array` and `main`) and rejects any `@link_section(name)` matching the cross-OS loader execution blocklist with **`E0327 (ForbiddenSandboxBypassAttribute)`**:

| Binary Format / Target | Blocked `@link_section` Prefixes & Substrings (`E0327`) | Pre-`main` / Post-`main` Loader Execution Vector Closed |
| :--- | :--- | :--- |
| **ELF** (`Linux`, `BSD`, Embedded) | `.init`, `.init_array`, `.preinit_array`, `.ctors`, `.fini`, `.fini_array`, `.dtors`, `.iplt`, `.rela.iplt`, `.got`, `.plt` | Blocks `DT_PREINIT_ARRAY` (runs before DSOs), `DT_INIT`/`DT_INIT_ARRAY`, reversed `.ctors`, `DT_FINI_ARRAY`, and `IRELATIVE` `IFUNC` injection. |
| **Mach-O** (`macOS`, `iOS`) | `__mod_init_func`, `__mod_term_func`, `__kmod_init`, `__kmod_term`, `__interpose`, `__la_symbol_ptr`, `__nl_symbol_ptr` (across any segment) | Blocks `dyld` `S_MOD_INIT_FUNC_POINTERS`, `S_INTERPOSING` (`__DATA,__interpose` symbol hijacking), lazy/non-lazy symbol pointer overwrites, and XNU initializers. |
| **PE/COFF** (`Windows`) | `.crt$xi`, `.crt$xc`, `.crt$xl`, `.crt$xp`, `.crt$xt`, `.tls` (case-insensitive) | Blocks MSVC `_initterm_e` (`.CRT$XI*`), `_initterm` (`.CRT$XCU`), pre-`main` `ntdll` `PIMAGE_TLS_CALLBACK` (`.CRT$XLB`–`.CRT$XLZ`), and CRT terminators. |
| **WebAssembly** (`wasm-ld`) | `.init_array`, `__wasm_call_ctors`, `start` | Blocks `wasm-ld` synthesized constructor wrappers and Wasm `start` section hooks. |

Aligning with and strengthening Rust 2024 Edition RFC 3325, every `extern` declaration, `@link_name`, `@export`, permitted data `@link_section` (such as bare-metal `.rodata.boot`), and inline/global `asm` taints its item with `EffectCapabilityMask.ffi | EffectCapabilityMask.unsafe_op`. Furthermore, any item carrying `@export`, `@link_section`, or global `asm` is promoted to an **Ambient Package Root**: both `ffi | unsafe_op` and the full `inferred_effects` of the exported item's body are unioned unconditionally into its package's `ambient_caps` even if unreferenced by `main`, preventing silent `libc` symbol interposition. Finally, to eliminate `Cackle`'s host-OS blindspot where Windows-only malware goes unseen on Linux CI, `DR-12`'s `ItemTree` pass pre-scans **all** `@cfg(…)` branches of external dependencies (`PackageId >= 2`) for `std::fs`, `std::net`, `std::env`, `std::process`, `extern`, `unsafe`, `asm`, and linker attributes, making `corex.lock`'s `caps` list invariant across host operating systems.

pub fn isForbiddenExecutableSection(raw_section: []const u8) bool {
    const trimmed = std.mem.trim(u8, raw_section, " \t\r\n");
    if (trimmed.len == 0) return false;
    if (std.ascii.eqlIgnoreCase(trimmed, "start")) return true;

    const prefixes = [_][]const u8{
        ".init",          // ELF .init, .init_array, .init_array.N
        ".preinit_array", // ELF DT_PREINIT_ARRAY (runs before DSOs)
        ".ctors",         // ELF legacy constructors
        ".fini",          // ELF .fini, .fini_array
        ".dtors",         // ELF legacy destructors
        ".iplt",          // ELF STT_GNU_IFUNC PLT
        ".rela.iplt",     // ELF IRELATIVE relocation injection
        ".got",           // Global Offset Table overwrite
        ".plt",           // Procedure Linkage Table overwrite
        ".crt$xi",        // Windows PE C initializers (_initterm_e)
        ".crt$xc",        // Windows PE C++ initializers (.CRT$XCU _initterm)
        ".crt$xl",        // Windows PE TLS callbacks (.CRT$XLB..XLZ before main)
        ".crt$xp",        // Windows PE pre-terminators
        ".crt$xt",        // Windows PE terminators
        ".tls",           // Raw PE TLS directory / callback injection
    };
    for (prefixes) |prefix| {
        if (trimmed.len >= prefix.len and std.ascii.eqlIgnoreCase(trimmed[0..prefix.len], prefix)) {
            return true;
        }
    }

    const substrings = [_][]const u8{
        "__mod_init_func",  // Mach-O S_MOD_INIT_FUNC_POINTERS (__DATA / __DATA_CONST)
        "__mod_term_func",  // Mach-O S_MOD_TERM_FUNC_POINTERS
        "__kmod_init",      // Darwin XNU kernel-extension init
        "__kmod_term",
        "__interpose",      // Mach-O dyld S_INTERPOSING (__DATA,__interpose) symbol hijacking
        "__la_symbol_ptr",  // Mach-O lazy symbol pointer table overwrite
        "__nl_symbol_ptr",  // Mach-O non-lazy symbol pointer table overwrite
        "__wasm_call_ctors",
    };
    for (substrings) |sub| {
        if (std.ascii.indexOfIgnoreCase(trimmed, sub) != null) return true;
    }
    return false;
}

## 3. Deliverable 2: @no_alloc and @no_panic Verification Rules, Shortest-Witness Diagnostic Renderer, and E03xx / W03xx Catalog

### 3.1 Exact @no_alloc Semantics on MIR (`alloc == 0`)

In real-time audio pipelines, interrupt handlers, kernel schedulers, and GPU shaders (`DR-20` `D-10`), dynamic heap allocation introduces unbounded latency, memory fragmentation, and allocator lock contention. At the same time, CoreX's zero-GC MVS architecture relies on pre-reserved arenas and slab pools (`DR-01`, `DR-06`). CoreX defines `@no_alloc` precisely by **whether an operation can invoke a dynamic backing heap/slab allocator or OS virtual-memory mapping**. Note a deliberate distinction from Clang's `[[clang::nonallocating]]` (which rejects both `new` and `delete` because global heap `free` can acquire allocator locks): in CoreX, dropping an already-owned heap value (`own Vec[T]`) sets `alloc = 0` and `blocking_sync = 1`, so `@no_alloc` verifies strictly zero heap growth while `@no_alloc @no_block` verifies Clang's full lock-free + allocation-free `[[clang::nonblocking]]` contract:

| Memory Operation / Construct in `.cx` | `alloc` Bit | `blocking_sync` Bit | Verification Rationale & Real-Time Idiom |
| :--- | :--- | :--- | :--- |
| **Stack locals, fixed arrays `[T; N]`, `@local` closures** | **`0` (Allowed)** | `0` | Pure stack-pointer offset; worst-case call-tree depth is statically verifiable via `@max_stack(N)` (`DR-20` `D-02`). |

In `FnContractScratchMask`, Pass 3 also propagates `DR-20` `D-04`'s `scratch_touch_mask: u2` and `scratch_rewind_mask: u2` bottom-up across the call graph. Whenever a caller passes `&mut Context.scratch[i]` as an output `BumpArena` parameter while `callee.scratch_rewind_mask` has bit `i` set, `callee` would rewind the destination arena it is populating. `Context::scratch_scope(&[&out_arena])` statically selects non-conflicting slot `1 - i`, whereas manually hardcoding colliding scratch slots halts compilation with **`E0328 (ScratchArenaPingPongConflict)`**.

### 3.2 Exact @no_panic Semantics on MIR (`may_panic == 0`)

Unlike Rust's `dtolnay/no-panic` crate – which inserts a drop guard calling a nonexistent linker symbol and relies on LLVM optimizations to delete it, failing at `-O0` or on un-unrolled loops with spanless linker errors – CoreX's `@no_panic` is verified deterministically on Phase 6 `MIR` at the conclusion of **Pass 4 (Demand-Sliced Pentagon `Intv × Sub` with `MAX_SUB_VARS = 256` per `DR-20` `Fix-06A`)**. Paired with `@max_stack(N)` (`DR-20` `D-02`, diagnostic `E0316`) to statically bound stack storage exhaustion (closing SPARK Silver's `Storage_Error` exclusion), `@no_panic` requires every trap-capable `MIR` instruction to be discharged by one of seven Pass 4 abstract-state predicates:

| # | `MIR` Instruction / Construct | Pass 4 Abstract State Discharge Predicate ($\text{State}(\ell) = \langle b^*, s^* \rangle \neq \bot$) | Residual `may_panic` if Unproven | Idiomatic `@no_panic` Safe Rewrite in `.cx` |
| :--- | :--- | :--- | :--- | :--- |
| **1** | **Slice / Array Index** (`bounds.check %idx, %len`) | $\text{inf}(b^*(\text{idx})) \ge 0 \;\land\; \big(\text{len} \in s^*(\text{idx}) \lor \text{sup}(b^*(\text{idx})) < \text{inf}(b^*(\text{len}))\big)$. *(Proven OOB is always hard error `E0307`.)* | **`1` (`E0321`)** | `if idx < s.len() { s[idx] }`, `for x in s`, `s[idx % N]` (`N > 0`), or `s.get(idx)` (`Option[&T]`). |
| **2** | **Sub-slice Range** (`slice.range %s, %lo, %hi, %len`) | $0 \le \text{inf}(b^*(\text{lo})) \;\land\; \big(\text{hi} \in s^*(\text{lo}) \lor \text{sup}(b^*(\text{lo})) \le \text{inf}(b^*(\text{hi}))\big) \;\land\; \big(\text{len} \in s^*(\text{hi}) \lor \text{sup}(b^*(\text{hi})) \le \text{inf}(b^*(\text{len}))\big)$. | **`1` (`E0321`)** | `s.get_range(lo..hi)` (`Option[[T]]`) or dominating `if lo <= hi and hi <= s.len()`. |
| **3** | **Unsigned Div / Rem** (`div_u %x, %d`, `rem_u %x, %d`) | $\text{inf}(b^*(d)) \ge 1$ (divisor proven non-zero via `Intv`, `if d != 0` guard, or `NonZeroU*` range type). | **`1` (`E0321`)** | `x.checked_div(d)` / `x.checked_rem(d)` or `d: u64 is 1..u64::MAX`. |
| **4** | **Signed Div / Rem** (`div_s %x, %d`, `rem_s %x, %d` on W-bit `iW`) | $0 \notin b^*(d) \;\land\; \neg\big(\text{MIN}_W \in b^*(x) \land -1 \in b^*(d)\big)$ (discharges both `/ 0` and hardware `INT_MIN / -1` `#DE` fault). | **`1` (`E0321`)** | `x.checked_div(d)`, `x.wrapping_div(d)`, or guard `if d != 0 and not (x == i64::MIN and d == -1)`. |
| **5** | **Checked Arithmetic & Shifts** (`+`, `-`, `*`, `-x`, `<<`, `>>`) | Arithmetic: $b^*(x) \circledast b^*(y) \subseteq [\text{MIN}_T, \text{MAX}_T]$ (`DR-20` `D-11` VRP). Shift on W-bit integer: $b^*(k) \subseteq [0, W - 1]$. *(Wrapping `+%` and saturating `+\|` always have `may_panic = 0`.)* | **`1` (`E0321`)** | `a +% b` (wrapping), `a +\| b` (saturating), `a.checked_add(b)`, or `x << (k & 63)`. |
| **6** | **Range Narrowing & Unwraps** (`.narrow()`, `.unwrap()`, `panic`, `todo`, `assert`) | Discharged **only** if `Intv` proves `.narrow()` fits $[\text{LO}, \text{HI}]$ (`D-11`) or proves the `MirTerm.panic` block unreachable ($\text{State}(\text{bb}) = \bot_{\text{Pntg}}$). | **`1` (`E0321`)** | Propagate via `?` (`Result[T, E]`), match `.Some(v)` / `.None`, or call `.try_narrow()`. |
| **7** | **MVS `inout` `subscript`/`yield` Non-`Copy` Guard** (`DR-20` `Fix-06B`) | When an `inout` `subscript` vacates a non-`Copy` (`AutoDrop`/`@linear`) slot, caller's `yield` scope $B_{\text{yield}}$ requires $\mathcal{E}(B_{\text{yield}}).\text{may\_panic} == 0$ to omit `abort` guard (`W0329`). | **`1` (`E0321` in `@no_panic`; `W0329` + `abort` otherwise)** | Keep operations inside `&mut container[i]` projection panic-free (early `?` error returns execute post-`yield` `defer` writebacks cleanly). |

### 3.3 Shortest-Witness Call-Chain Reconstruction Algorithm

During normal builds, `DR-17` allocates zero trace strings or per-bit provenance arrays, storing only the `2-byte` `inferred_effects` / `direct_effects` columns and the `12-byte` `WitnessCallEdge` CSR graph. When a contract (`@no_alloc`, `@no_panic`, `@no_block`) or package policy (`corex.toml` / `corex.lock`) fails on single capability/effect bit `bit_mask`, the diagnostic engine runs lazy `O(V_R + E_R)` breadth-first search over `FnSummaryStore` to reconstruct a guaranteed minimal-hop witness chain:

```zig
/// Reconstructs a guaranteed minimal-hop call chain from `root_fn` to the closest
/// concrete `DefIndex` whose intraprocedural `direct_effects` (or indirect ceiling) sets `bit_mask`.
pub const WitnessHop = struct {
    caller_def: DefIndex,
    callee_def: DefIndex, // `.none` for terminal unconstrained indirect fn-ptr / vtable site
    site_token: TokenIndex,
    edge_kind: WitnessEdgeKind,
    via_higher_order_callee: DefIndex = .none,
};

pub const ShortestWitness = struct {
    violating_bit: EffectCapabilityMask,
    hops: []WitnessHop,
    leaf_def: DefIndex,
    leaf_mir_token: TokenIndex,
    leaf_reason_detail: StringId,
};

fn findEnclosingDirectCallee(preceding_edges: []const WitnessCallEdge, tok: TokenIndex) DefIndex {
    var i: usize = preceding_edges.len;
    while (i > 0) {
        i -= 1;
        if (preceding_edges[i].site_token == tok and preceding_edges[i].meta.kind == .direct_call) {
            return preceding_edges[i].callee_def;
        }
    }
    return .none;
}

fn unwindChain(
    arena: *BumpArena,
    parent_hop: []const WitnessHop,
    root_fn: DefIndex,
    last_node: DefIndex,
    extra_tail: ?WitnessHop,
    leaf_def: DefIndex,
    leaf_tok: TokenIndex,
    leaf_detail: StringId,
    bit_mask: u16,
) !ShortestWitness {
    var depth: usize = if (extra_tail != null) 1 else 0;
    var cur = last_node;
    while (cur != root_fn) : (depth += 1) {
        cur = parent_hop[cur.asInt()].caller_def;
    }
    var hops = try arena.allocSlice(WitnessHop, depth);
    var write_idx = depth;
    if (extra_tail) |tail| {
        write_idx -= 1;
        hops[write_idx] = tail;
    }
    cur = last_node;
    while (cur != root_fn) {
        write_idx -= 1;
        const hop = parent_hop[cur.asInt()];
        hops[write_idx] = hop;
        cur = hop.caller_def;
    }
    return .{
        .violating_bit = @bitCast(bit_mask),
        .hops = hops,
        .leaf_def = leaf_def,
        .leaf_mir_token = leaf_tok,
        .leaf_reason_detail = leaf_detail,
    };
}

pub fn reconstructShortestWitness(
    arena: *BumpArena,
    store: *const FnSummaryStore,
    root_fn: DefIndex,
    bit_mask: u16,
    resolveLeafTokenFn: *const fn (DefIndex, u16) struct { tok: TokenIndex, detail: StringId },
) !ShortestWitness {
    assert(@popCount(bit_mask) == 1);
    const num_fns: usize = store.summaries.len;
    const inferred_col = store.summaries.items(.inferred_effects);
    const direct_col = store.summaries.items(.direct_effects);
    const cb_mask_col = store.summaries.items(.forwarded_cb_mask);
    const row_offsets = store.csr_row_offsets.items;
    const edges = store.csr_edges.items;

    if ((direct_col[root_fn.asInt()].asBits() & bit_mask) != 0) {
        const leaf = resolveLeafTokenFn(root_fn, bit_mask);
        return .{
            .violating_bit = @bitCast(bit_mask),
            .hops = &[_]WitnessHop{},
            .leaf_def = root_fn,
            .leaf_mir_token = leaf.tok,
            .leaf_reason_detail = leaf.detail,
        };
    }

    var visited = try arena.allocSlice(bool, num_fns);
    var parent_hop = try arena.allocSlice(WitnessHop, num_fns);
    var queue = try arena.allocSlice(DefIndex, num_fns);
    var q_head: usize = 0;
    var q_tail: usize = 0;

    visited[root_fn.asInt()] = true;
    queue[q_tail] = root_fn;
    q_tail += 1;

    while (q_head < q_tail) : (q_head += 1) {
        const caller_def = queue[q_head];
        const caller_idx = caller_def.asInt();
        const start_e = row_offsets[caller_idx];
        const end_e = row_offsets[caller_idx + 1];

        // Edges in `csr_edges[start_e..end_e]` are sorted by ascending `site_token`,
        // ensuring deterministic shortest-path tie-breaking across OS/thread schedules (DR-01).
        var e_idx: usize = start_e;
        while (e_idx < end_e) : (e_idx += 1) {
            const edge = edges[e_idx];
            if ((edge.meta.edge_effect_mask & bit_mask) == 0) continue;

            if (edge.callee_def == .none) {
                return try unwindChain(arena, parent_hop, root_fn, caller_def, .{
                    .caller_def = caller_def,
                    .callee_def = .none,
                    .site_token = edge.site_token,
                    .edge_kind = edge.meta.kind,
                }, .none, edge.site_token, .empty, bit_mask);
            }

            const callee_def = edge.callee_def;
            const callee_idx = callee_def.asInt();

            if ((inferred_col[callee_idx].asBits() & bit_mask) != 0 and !visited[callee_idx]) {
                visited[callee_idx] = true;
                parent_hop[callee_idx] = .{
                    .caller_def = caller_def,
                    .callee_def = callee_def,
                    .site_token = edge.site_token,
                    .edge_kind = edge.meta.kind,
                    .via_higher_order_callee = if (edge.meta.kind == .forwarded_cb_arg)
                        findEnclosingDirectCallee(edges[start_e..e_idx], edge.site_token)
                    else
                        .none,
                };

                if ((direct_col[callee_idx].asBits() & bit_mask) != 0 or
                    (cb_mask_col[callee_idx] == 0 and row_offsets[callee_idx] == row_offsets[callee_idx + 1]))
                {
                    const leaf = resolveLeafTokenFn(callee_def, bit_mask);
                    return try unwindChain(
                        arena, parent_hop, root_fn, callee_def, null, callee_def, leaf.tok, leaf.detail, bit_mask,
                    );
                }
                queue[q_tail] = callee_def;
                q_tail += 1;
            }
        }
    }
    unreachable;
}
```

## 4. Deliverable 3: corex.lock and corex.toml Capability Schema, .cxi Digest Seam, and corex check / corex lsp Specification

### 4.1 Package Capability Attribution and Transitive Non-Laundering Calculus

Post-link object/DWARF tools like `Cackle` suffer from generic and callback misattribution when a host binary passes an I/O closure into a pure generic combinator in a third-party crate, while process-wide sandboxes like Deno grant the host application's `--allow-net` flag to every imported dependency. CoreX avoids both pitfalls because every `DefId` belongs uniquely to the `PackageId` owning its `FileId` in `VfsSourceMap` (`DR-11` §2.4), and `forwarded_cb_mask` evaluates caller-supplied `@local` closures at the caller's call site rather than mutating the library's `FnRegionSummary`. Passing a `net`-using closure from `app` (`PackageId == 0`) into `serde_json` (`PackageId >= 2`) attributes `net` strictly to `app`, leaving `serde_json` at `0x0000` (`pure`).

For every resolved `PackageId` $P$, Phase 6 Pass 3 and Phase 9 compute three ordered capability sets ($\text{AmbientCaps}(P) \sqsubseteq \text{ReachableCaps}(P) \sqsubseteq \text{SurfaceCaps}(P)$):

| Package Capability Tier | Exact Mathematical Definition (Masked to `LOCKFILE_CAP_BITS = 0x033F`) | Security & Audit Role |
| :--- | :--- | :--- |
| **`AmbientCaps(P)`** | Union of `(ffi \| unsafe_op \| inferred_effects(f))` over all `@export`, `@link_section`, and global `asm` items declared in $P$. | Captures authority active at link/load time even when zero functions in $P$ are called by `main`. |
| **`ReachableCaps(P)`** | `AmbientCaps(P)` unioned with `direct_effects(f)` (and `reify_fn_addr` / `reify_vtable` targets in $P$) over all functions $f \in P$ reachable from active build entrypoints (`main`, `[[bin]]`, or `@test` in `corex test`). | Dead-code-pruned capability footprint actually linked into the target binary. |
| **`SurfaceCaps(P)`** | `AmbientCaps(P)` unioned with `inferred_effects(f)` over all `pub` items of $P$ **plus** the cross-OS `@cfg(…)` declaration pre-scan. | Canonical target-invariant baseline serialized as `caps` in `corex.lock` and `surface_caps` in `.cxi`. |

To prevent **transitive capability laundering**, let $\text{Deps}^*(D)$ denote direct dependency $D$ together with all packages transitively reachable from $D$ in `corex.lock`. CoreX enforces both per-package lockfile non-escalation ($\forall Q:\; \text{SurfaceCaps}(Q) \sqsubseteq \text{LockedCaps}(Q)$) and dependency-subtree containment:

$$\bigcup_{Q \in \text{Deps}^*(D)} \text{ReachableCaps}(Q) \;\sqsubseteq\; \text{AllowedSubtreeCaps}(D)$$

Thus, a direct dependency `corex-http` granted `allow_caps = ["net", "clock"]` cannot pull in a transitive compression helper `mini-zlib` that spawns a shell via `std::process::Command` (`process`), unless `[security.package.mini-zlib]` explicitly grants `process` in the root workspace `corex.toml`.

#### Trust-on-First-Lock vs. Upgrade Escalation Blocking Protocol

1.  **Initial Lock (`corex add <pkg>` or first `corex build` of a new dependency):** If `[security].default_allow_caps`, `deny_caps`, or `allow_caps` is present in `corex.toml`, `corex` checks `SurfaceCaps(P)` against those bounds immediately (`E0324` on violation). When `[security]` is omitted, `corex` commits `caps` and `cxi_blake3` to `corex.lock` (**Trust-on-First-Lock**) and prints a one-time monochrome CLI notice (`⚠ capability baseline locked: corex-tls v0.8.2 uses [entropy, net]`) whenever `CORE_SANDBOX_BITS` is non-zero.
2.  **Steady-State and Hermetic CI Builds (`corex build`, `--locked`, `--frozen`):** After Phase 6 Pass 3 computes `SurfaceCaps(P)` and `.cxi`, `corex` verifies `SurfaceCaps(P) == LockedCaps(P)` and `computed_cxi_blake3 == locked_cxi_blake3`, halting with `E0324` on any discrepancy.
3.  **Dependency Upgrades (`corex upgrade` or version bump in `corex.toml`):** `corex` computes `Escalated = SurfaceCaps(P_new) \ LockedCaps(P_old)`. When `Escalated == 0` (capabilities unchanged or narrowed), `corex.lock` updates silently. When `Escalated != 0` and the gained bits are not already pre-authorized in `corex.toml` `allow_caps`, **`corex upgrade` aborts with `E0324`**, renders the shortest-witness trace inside `P_new`, and leaves `corex.lock` unmodified until the developer explicitly runs `corex upgrade <pkg> --accept-caps=<caps>` or updates `allow_caps`.

### 4.3 Phase 9 .cxi Public-Interface Digest Seam (`DR-20` `D-08` Seam #7)

### 4.5 End-to-End .cx Showcase: Zero-Annotation Purity, @no_alloc @no_panic Hot Path, and Callback Forwarding

The `.cx` module below conforms strictly to `DR-02`, `DR-03`, `DR-06`, and `DR-20` (`[T]` generics, `&` / `&mut` MVS modes, `+%` / `-%` wrapping operators, contextual `.Ok`/`.Err`, and zero lifetime annotations):

```rust
// File: src/audio_dsp_pipeline.cx
mod audio_dsp_pipeline;

use std::mem::FixedArena;

pub enum DspErr {
    ScratchExhausted,
    EmptyWindow,
}

// [1] ORDINARY UNANNOTATED HIGHER-ORDER HELPER:
// Zero `@no_alloc`, `@no_panic`, or effect-polymorphic type variables!
// Pass 3 automatically infers:
//   • inferred_effects  = 0x0000 (PURE: Pentagon proves `i < samples.len()` in 0..len loop)
//   • forwarded_cb_mask = 0b0010 (param 1 `transform` is a non-escaping `@local` closure)
pub fn map_samples_in_place(samples: &mut [f32], transform: &fn(f32) -> f32) {
    for i in 0..samples.len() {
        // Pass 4 Pentagon: `i in [0, samples.len() - 1]` and `samples.len() in Sub(i)`
        // -> bounds.check is erased (`may_panic = 0`) identically at -O0 and -O3.
        samples[i] = transform(samples[i]);
    }
}

// [2] HARD REAL-TIME AUDIO CALLBACK CONTRACT (`@no_alloc @no_panic @no_block`):
// Verified at Phase 6 Pass 4 with zero heap allocations and zero residual panic edges.
@no_alloc
@no_panic
@no_block
@max_stack(4096)
pub fn process_audio_frame(
    io_samples: &mut [f32; 256],
    fir_taps: &[f32; 16],
    gain: f32,
) -> Result[f32, DspErr] {
    // Fixed stack scratch buffer + FixedArena: `alloc == 0` and `blocking_sync == 0`.
    var stack_bytes: [u8; 2048] = [0; 2048];
    var fixed_arena = FixedArena::over_slice(&mut stack_bytes);

    let scratch_win = fixed_arena
        .try_alloc_slice[f32](256)
        .map_err(|_| DspErr::ScratchExhausted)?;

    // Calling unannotated `map_samples_in_place` with a pure `@local` closure:
    // Instantiated site effect = PURE | PURE = 0x0000 -> satisfies @no_alloc/@no_panic/@no_block.
    map_samples_in_place(&mut io_samples[0..256], &|sample| sample * gain);

    var peak: f32 = 0.0;
    for n in 0..256 {
        var acc: f32 = 0.0;
        for j in 0..16 {
            // Pentagon + VRP: `((n +% 256) -% j) & 255` has Intv [0, 255] < 256 (`io_samples.len()`)
            // and `j` has Intv [0, 15] < 16 (`fir_taps.len()`) -> 0 bounds checks, 0 panic edges.
            let ring_idx = ((n +% 256) -% j) & 255;
            acc += io_samples[ring_idx] * fir_taps[j];
        }
        scratch_win[n] = acc;
        if acc > peak {
            peak = acc;
        }
    }

    for i in 0..256 {
        io_samples[i] = scratch_win[i];
    }
    .Ok(peak)
}
```
