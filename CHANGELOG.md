## [Unreleased]

### Added

-   Initial CoreX language specification, research architecture (`DR-01`–`DR-15`), and multi-stage bootstrap and verification governance.
-   Stage 0 Zig (`0.17.0`) bootstrap workspace (`build.zig`, `stage0/src/`, `stage0/bootstrap.c`) installing the unified `corex` binary into `build/stage0/`.
-   Foundational memory and syntax arenas (`BumpArena` with 64 KiB 16-byte-aligned slabs and $O(1)$ `Checkpoint`/`restore`, `StringInterner` with `Wyhash(0)`, `TokenBuffer`, `LosslessCstArena`, `AstArena` / `AstStore`, and compact 32-bit entity handles).
-   Content-addressable `VfsSourceMap` (`SourceMap`) with `< 16 KiB` NUL-terminated arena storage, `>= 16 KiB` read-only `mmap`, in-memory overlays, `.cxtree` binary manifest headers, and $O(\log L)$ `LineIndex` (`LF`/`CRLF`, UTF-8, and UTF-16 columns).
-   Centralized `DiagnosticSink` (`E00xx`–`E05xx` / `W00xx`–`W05xx` catalog and 100-error cap), `TransactionalPatcher`, monochrome Unicode + ANSI `DiagnosticRenderer` (`cli/style.zig`, `cli/box_draw.zig`, `diag/renderer.zig`), and `corex` CLI command router (`build`, `run`, `check`, `test`, `fmt`, `upgrade`, `lsp`, `bench`).
-   Multi-tier verification and benchmark harnesses (`tests/unit/`, `tests/snapshots/`, `tests/fuzz/`, `tests/drift/`, and `bench/suites/`).
-   High-speed non-backtracking DFA lexer and token stream (`stage0/src/lexer.zig`) supporting all 112 `TokenKind` variants (`0..111`), $O(1)$ keyword/primitive-type classification, disjoint identifier casing invariant (`.underscore`, `.ident`, `.type_ident`, `.const_ident`) with `W0201` auto-fix normalization, lossless `TriviaPiece` attachment and coalescing, fault-tolerant `E0101`–`E0104` / `W0101` recovery, golden token/diagnostic snapshots, 10,000,000+ input lossless round-trip fuzzing (`tests/fuzz/phase1_lexer_fuzz.zig`), and `phase1_bench` throughput benchmarks.
-   Fault-tolerant incremental recursive-descent and Pratt parser (`stage0/src/parser.zig`) lowering `TokenBuffer` streams into Carbon-style pre-order `LosslessCstArena` nodes and typed `AstArena` / `AstStore` representations across the complete CoreX v1.0 EBNF grammar (`DR-03` §5.3–5.5 & §6 Showcases 1–4), with `TokenSet128` (`u128`) synchronization sets, bounded recursion depth (`MAX_PARSE_DEPTH = 512`), `E0201`–`E0203` / `W0201` recovery, semantic holes and mid-keystroke LSP completion nodes, item-boundary incremental re-parsing (`reparseIncremental`), golden CST/AST and diagnostic snapshots, structure-aware and incremental fuzzing (`tests/fuzz/phase2_parser_fuzz.zig`), and `phase2_bench` throughput benchmarks.
-   Demand-driven incremental query engine (`stage0/src/query_db.zig` `CompilerDb`) with 3-tier input `Durability` (`.low`, `.medium`, `.high`), 128-bit `Wyhash` and `BLAKE3` structural fingerprinting (`Fingerprint128`), 8-byte `QueryKey`, 40-byte `MemoHeader`, Early Cutoff `changed_at` backdating, position-independent `ItemTree` signature (`item_tree_sig_proj`) and body (`body_ast_proj`) firewall projections, cycle detection (`error.DependencyCycle`), and cooperative cancellation (`unwindIfCancelled`), paired with the `corex fmt` hybrid steerable Wadler–Lindig formatter (`stage0/src/fmt_engine.zig` & `stage0/src/cli/router.zig`) featuring 8-byte `DocInst` / `DocArena` with $O(1)$ `flat_width` backpatching, `DocRenderer` with `line_suffix` trailing-comment flushing, 100% `Leading`/`Trailing`/`Dangling` comment preservation, `// corex fmt: off` / `on` directives, `--check` and `--fix` casing/semicolon normalization, golden `.snap` snapshots, idempotency and early-cutoff fuzzing (`tests/fuzz/phase3_fmt_fuzz.zig`), and `phase3_bench` throughput benchmarks.
-   Module and lexical scope name resolver (`stage0/src/symbol_resolver.zig`) and canonical bidirectional type checker (`stage0/src/type_system.zig`) wired into `CompilerDb` (`resolve_signatures`, `def_signature`, `typecheck_body`), featuring `ScopeArena` (`ScopeId`), `SymbolTable` with disjoint `Type`/`Value`/`Const` namespaces, `mod` and `use` path/alias/group/glob import resolution, `pub` visibility hygiene (`E0409`), bounded Damerau–Levenshtein / Jaro–Winkler typo suggestions (`E0403`), unused binding checks (`W0402`), the 14-byte zero-padding SoA `TypeNode` `InternPool` (`TypeArena`) pre-populating static slots `0..63`, $O(1)$ 32-bit `TypeGroupMask` algebra across the 19 primitives and 11 Constrained Type Groups, user-defined Type Groups, Bind-Once (`E0404`) vs. Bind-Many (`any Group`) generics with 16-entry inline `SubstitutionMap`, `distinct` newtype isolation (`E0405`), `~T` underlying-type approximation (`E0402`), `is` range refinements (`E0406`), `bit_field` width verification, `#soa` column slice projection, contextual `.Variant` inference (`E0407`), `@overload` specificity disambiguation (`E0400`), `Result[T, E]` / `T?` postfix `?` propagation (`E0410`) with `@from` (`FromError`) upcasting (`E0411`), `catch |err|`, `let … else` divergence verification (`E0412`), `defer` / `errdefer |err|` checks, `@must_use` / `Result` discard enforcement (`E0413` / `E0414`), Maranget pattern exhaustiveness (`E0415`) and unreachable arm (`W0401`) analysis, golden diagnostic snapshots, fault-tolerance and incremental parity fuzzing (`tests/fuzz/phase4_typecheck_fuzz.zig`), and `phase4_bench` throughput benchmarks.
