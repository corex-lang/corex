# Deterministic Concurrency and Fault-Injection Simulation and Zero-Config Coverage-Guided Native Fuzzing Specification for CoreX

CoreX (`corex test`) delivers FoundationDB- and TigerBeetle-style **Deterministic Simulation Testing (`corex test --sim`)** alongside zero-configuration **Coverage-Guided Structure-Aware Fuzzing (`corex test --fuzz`)** with **zero production runtime overhead** because safe CoreX code holds no ambient OS authority. Every dynamic memory allocation, monotonic or wall-clock read, hash-seed or cryptographic random draw, hierarchical cancellation check, and completion I/O submission (`io_uring`, `IOCP`, `kqueue`, `wasm32`) already traverses the explicit 64-byte **`Context`** parameter passed in a dedicated register (`r10` on `x86_64`, `x8` on `aarch64`, or omitted when Pass D5 proves `is_contextless == true`). In `--release` builds, middle-end `MIR` inlining (`Pass R1`) statically devirtualizes `Context.reactor` to the target platform's native OS reactor and folds `std::sim::buggify()` probes to constant `false`, emitting zero indirect vtable calls and zero dead fault branches. In `--sim` builds, `corex test` binds `Context` to a single-threaded **`SimWorld`** driven by one `SplitMix64`-seeded `Xoshiro256**` stream that virtualizes time whenever all tasks are durably blocked, permutes `TaskGroup` wakeups via **Probabilistic Concurrency Testing (PCT)**, verifies `DR-08` `@linear` DMA buffer quarantines and `Fix-08B` `CompletionReaper` cancellation races, and injects both exhaustive sequential `FailingAllocator` out-of-memory (`OOM`) sweeps and Swarm-scheduled I/O errors with bit-exact replay from a single 64-bit `--seed`.

In parallel, `corex test --fuzz` upgrades `DR-15`'s PRNG property runner into an in-process, zero-`libFuzzer` coverage-guided engine without inflating Stage-0 (Zig) or Stage-1 (`.cx`) `MIR` complexity. Rather than inserting edge counters into `MIR` – which would require duplicate lowering across three backends and obstruct loop vectorization – Phases 7 and 11 (`Pre-v0.0.1`) wire LLVM 20–23's `llvm::SanitizerCoveragePass` (`SCK_Edge`, `Inline8bitCounters`, `PCTable`, `TraceCmp`, `TraceDiv`) at `OptimizerLastEP` inside the shared `src/corex_llvm.cpp` C++20 bridge, leaving Stage-0 Zig `MIR` untouched. In Phase 13.0 (`Post-v0.0.1`), the self-hosted Tier C (`--dev`) single-pass backend adds direct branchless saturating 8-bit edge counters for sub-50ms edit-to-fuzz startup. An in-tree `.cx` runtime (`std::test::fuzz`) exports all 17 SanitizerCoverage C-ABI symbols (eliminating undefined or duplicate symbol errors when linking C libraries via `DR-10`), scans 8-bit counters with 32-byte SIMD logarithmic bucketing, solves magic-constant comparisons via a 16 KiB L1-resident **Table of Recent Compares (`TORC`)**, and pairs byte-level mutation with Hypothesis Conjecture-style **shortlex shrinking** over span-delimited **`ChoiceCursor`** streams (`@derive(Arbitrary)`). Every panic, SAST residual check failure, leak, or assertion violation is minimized automatically into a Git-committed regression file (`tests/fuzz/…/*.cxfuzz` or `tests/sim/…/*.cxsim`) that replays deterministically during standard `corex test` runs.

## 2. Deliverable 1 – Context Simulation Seam and Deterministic SimReactor, Virtual-Time, and OOM Fault-Injection Specification

### 2.1 Canonical 64-Byte Context Layout and Zero-Overhead Production Devirtualization

Consolidating `DR-08`'s completion reactor, `DR-09`'s `AbiClassifier` register rules (expanding `DR-09`'s initial 32-byte placeholder to incorporate `DR-15` and `DR-20`'s Phase 6–8 seams), `DR-15`'s dual-mode `AllocatorHandle`, and `DR-20` (`D-04` ping-pong scratch arenas, `D-06B` `FlightRecorder`, and the Phase 8 `ReactorVTable` seam) yields an exact **64-byte `Context` struct** (`nonnull noundef align(64) dereferenceable(64)`).

| Byte Offset | Field Name & `.cx` Type | Size | Production (`--release`) Binding | Simulation (`--sim`) Binding |
| :---: | :--- | :---: | :--- | :--- |
| `0..8` | `allocator: AllocatorHandle` | `8 B` | LSB-tagged pointer (`Bit 0 = 1` for `BumpArena`, `0` for thread slab allocator). | `AllocTag = 0` wrapping `SimFaultAllocator` (`FailingAllocator` + leak/double-free shadow map). |
| `8..24` | `scratch: [*mut Arena; 2]` | `16 B` | Thread-local 2-slot ping-pong `BumpArena` ring (`DR-20` `D-04`). | Per-`SimWorld` zero-initialized 64 KiB `BumpArena` pair with rewind-aliasing verification. |
| `24..32` | `reactor: *const ReactorVTable` | `8 B` | `&OS_NATIVE_REACTOR_VTABLE` statically devirtualized & inlined in Pass R1. | `&SIM_REACTOR_VTABLE` single-threaded discrete-event proactor, virtual clock & PRNG. |
| `32..40` | `reactor_ctx: *mut u8` | `8 B` | Core-local `LinuxFusionReactor` / `IocpReactor` / `KqueueReactor` / Wasm state. | `*mut SimWorld` owning `monotonic_ns`, `EventWheel`, `SimPrng`, and `InFlightOpTable`. |
| `40..48` | `cancel_token: CancelToken` | `8 B` | Hierarchical `TaskGroup` / `with_timeout` cancellation flag pointer. | `SimCancelTree` node tracked by `SimWorld` for adversarial cancellation-race scheduling. |
| `48..56` | `trace_sink: ?*mut FlightRing` | `8 B` | `None` unless `FlightRecorder` ring tracing is active (`DR-20` `D-06B`). | `SimEventLog` ring recording task wakeups, fault draws, and `ExecutionDigest` checkpoints. |
| `56..64` | `sim_and_diag_bits: u64` | `8 B` | Out-of-band `DiagSink` pointer (`Bit 0 = 0`: production runtime). | `Bit 0 = 1` (`is_sim`), `Bit 1` (`buggify_active`), `Bit 2` (`liveness_frozen`), `Bits 16..63` (`DiagSink`). |

Routing OS interaction through `Context.reactor` avoids `#cfg(sim)` conditional compilation across `std` and user libraries so the exact same `.cx` state-machine code runs in simulation and in production. To ensure **zero vtable indirection penalty in `--release` builds**, CoreX enforces three `MIR` lowering rules. First, during **Static VTable Devirtualization (`Pass R1`)**, when compiling in `--release` mode without `--sim`, `DR-09` Pass R1 (bounded cost-model `MIR` function inliner) folds every load of `context.reactor` to the constant target symbol `&OS_NATIVE_REACTOR_VTABLE` and inlines the target leaf function directly. Calling `std::time::Instant::now()` or `Reactor::submit_io()` lowers directly to a native Linux vDSO `clock_gettime` call, macOS commpage read, Windows `QueryPerformanceCounter` call, or shared-memory `io_uring` SQE store with zero indirect `call` instructions. Second, during **Compile-Time `buggify` Folding (`Passes D2 & D4`)**, controlled fault-injection intrinsics (`std::sim::buggify()`, `std::sim::buggify_prob(prob_ppm)`) lower to `MirOp.intrinsic_op` (`MirIntrinsicKind.buggify`). In non-`--sim` `--release` builds, Pass D2 folds `MirIntrinsicKind.buggify` to constant `false` and Pass D4 prunes the guarded fault-injection blocks to zero machine instructions. In `--dev` and `--sim` builds, `MirIntrinsicKind.buggify` executes a single register mask check (`(context.sim_and_diag_bits & 0x3) == 0x3`) and calls `context.reactor.buggify_gate` only inside an active simulation, implementing FoundationDB and Moonpool's two-phase activation rule (once per simulation seed to enable or disable each distinct call site, and once per execution at ~25% default probability or custom `prob_ppm` when enabled). Third, under **`contextless` Leaf Preservation (`Pass D5`)**, pure compute functions neither receive nor pass the `Context*` register in either `--release` or `--sim` builds.

### 2.3 Strict Determinism Contract – Eliminating and Trapping Host Entropy Leaks

Bit-exact simulation replay from a 64-bit seed breaks down whenever a single unseeded host syscall, Linux `vDSO` user-space clock read, ASLR stack/heap pointer address, OS thread wakeup race, or FMA rounding discrepancy influences control flow. CoreX enforces simulation determinism across seven compile-time and runtime layers:

| Entropy Vector | Underlying Hazard in Systems Tests | CoreX `--sim` Enforcement & Trapping Contract | Diagnostic / Trap Identifier |
| :--- | :--- | :--- | :--- |
| **1. Unseeded Host Syscalls & `vDSO` Reads** | Calling `clock_gettime` (which executes in user space via the Linux `vDSO` segment, escaping naive kernel `seccomp` filters), `getrandom`, `epoll_wait`, or `pthread_create` directly. | **Compile-Time (`MIR` SAST + `DR-17`):** Call-graph reachability from `@test` rejects any `@extern` FFI or host-OS call carrying `EffectCapabilityMask.LOCKFILE_CAP_BITS` (`fs \| net \| env \| process \| ffi \| clock \| entropy`) outside `Context`-routed `std` shims.<br>**Runtime (`--sim-strict`):** Overrides dynamic/PLT `clock_gettime`, `gettimeofday`, `time`, `getrandom`, and `arc4random_buf` symbols in the runner binary to panic immediately, backed by optional Linux `seccomp-bpf` (`SIGSYS`) syscall jailing. | Compile error **`E0331`** (`HostSyscallInSimGraph`) or runtime trap **`E_SIM_HOST_SYSCALL`**. |

### 2.4 SimReactor Execution Engine – Virtual Time, PCT Scheduling, and Fix-08B Quarantine Verification

#### 1. Discrete-Event Virtual Clock, Durably-Blocked Quiescence, and Wall-Clock Skew

`SimWorld` maintains two distinct virtual clocks: `monotonic_ns: u64` (initialized to `1_000_000_000` ns = `1.0 s` so uninitialized `0` timestamp bugs fail immediately) and `wall_epoch_ns: i64` (initialized to `1_767_225_600_000_000_000` ns = `2026-01-01T00:00:00Z` plus a mutable signed `wall_skew_ns: i64` offset). All pending timers (`async::sleep`, `async::with_timeout`) and simulated I/O completions are stored in a binary min-heap `event_wheel: Vec[SimEvent]` of **32-byte `SimEvent`** records (`{ deadline_ns: u64, tie_order: u64, cqe: ReactorCqe }`). Whenever multiple events share an identical `deadline_ns`, `tie_order` is drawn from `SimWorld.prng`, deterministically permuting simultaneous timeout-versus-completion races.

Unifying Go 1.25's `testing/synctest` bubble rule with FoundationDB `Flow`'s simulated event loop, **virtual time never advances while `run_queue` is non-empty**. Time progresses only when every live task in `SimWorld` reaches a **durably blocked** state (suspended on an `InFlightOpSlot`, a `TaskGroup` join barrier, or a `Channel` operation). Once `run_queue` empties, if `event_wheel` contains scheduled events, `SimWorld` pops the minimum `deadline_ns` entry, jumps `monotonic_ns = max(monotonic_ns, ev.deadline_ns)` in `O(log E)` heap operations with zero OS sleep, drains all co-scheduled events at `ev.deadline_ns` in `tie_order` sequence, and enqueues the woken `TaskHeader` IDs into `run_queue`. As illustrated in FoundationDB `Flow` analyses where 100 actors sleeping across a 60-second simulated window finish in microseconds of wall-clock time and a published C++ FoundationDB-style harness reporting a 1,200× speedup over real time, multi-hour retry and lease-expiration protocols execute in milliseconds. Conversely, if both `run_queue` and `event_wheel` are empty while the root coroutine has not completed (`state_idx != 0xFFFE`) or any `TaskGroup` retains unjoined children, `SimWorld` immediately aborts with **`E_SIM_DEADLOCK`**, printing the exact `.await` source span of every suspended task. Under Swarm fault injection, `SimWorld` also steps `wall_skew_ns` forward and backward across `[-300s, +300s]` while keeping `monotonic_ns` strictly monotonic, catching code that erroneously measures elapsed durations or timeouts with wall-clock `SystemTime` rather than `Instant`.

#### 2. Probabilistic Concurrency Testing (PCT) Task Permuter

Choosing runnable tasks via uniform step-by-step coin flips suffers exponential starvation on adversarial schedules: if Task A executes 40 consecutive cooperative steps and a race only manifests when Task B preempts *after* step 40, a uniform random walk hits that interleaving with probability $(1/2)^{40} \approx 9.09 \times 10^{-13}$.

`SimScheduler` therefore adopts **Burckhardt, Kothari, Musuvathi, and Nagarakatte's Probabilistic Concurrency Testing (PCT) algorithm** (ASPLOS 2010; implemented in Microsoft Coyote and AWS `shuttle`) as its primary scheduler. For a test creating at most $n$ concurrent tasks across $k$ scheduling steps and targeting bug depth $d \ge 1$, `SimScheduler` assigns each task $t \in \{0, \dots, n-1\}$ a distinct random initial priority $p[t]$ uniformly permuted over $\{d, d+1, \dots, d+n-1\}$, samples $d - 1$ random priority-lowering step indices $k_1, \dots, k_{d-1} \in \{1, \dots, k\}$ from `SimWorld.prng`, and always dispatches the enabled runnable task with maximum priority $p[t]$. Whenever the global step counter reaches $k_i$, the active task's priority drops to $p[t] \leftarrow d - i$, forcing a deterministic preemption to waiting lower-priority tasks (supplemented by a final priority drop immediately before root-task exit so late-manifesting invariant violations in sibling tasks are never masked).

By Burckhardt et al.'s worst-case theorem, a single PCT execution detects any concurrency bug of depth $d$ (defined as the minimum number of ordering constraints sufficient to trigger the bug) with probability:

$$P(\text{detect}) \ge \frac{1}{n \cdot k^{d-1}}$$

Applying the cumulative confidence relation $R = \lceil \ln(0.01) / \ln(1 - P) \rceil$ for 99% detection confidence on a typical `TaskGroup` test with $n = 8$ tasks and $k = 200$ steps:
-   **Depth $d = 1$ (ordering / missing-join bugs):** Single-run $P \ge 1 / 8 = 0.125$, reaching **99% detection confidence in 35 seeds**.
-   **Depth $d = 2$ (atomicity / two-way cancellation races):** Single-run $P \ge 1 / (8 \times 200) = 6.25 \times 10^{-4}$, reaching **99% detection confidence in 7,366 seeds**.

Across a multi-seed `--sim` campaign, `SimWorld` runs a portfolio cycling PCT depths $d \in \{1, 2, 3, 4\}$ on 80% of seeds and `SwarmRandomWalk` on 20% of seeds, while exposing `--sim-mode=dfs` for exhaustive depth-first schedule enumeration on small (`<= 4` task) synchronization unit tests.

#### 3. `@linear` DMA Quarantine and `Fix-08B` `CompletionReaper` Auditing

`SimReactor` directly enforces `DR-08` §4.3's two-phase DMA cancellation rules and `DR-20` `Fix-08B`. When an `@linear` `IoBuf` is submitted via `submit_io`, `SimReactor` transitions `InFlightOpSlot` to `active_in_flight` and poisons `[buf.ptr + filled .. buf.ptr + buf.cap)` with `0xAA` canary bytes until the completion timestamp fires, trapping any illegal `unsafe` read/write while simulated kernel DMA owns the buffer. When `TaskGroup` sibling failure or `with_timeout` calls `cancel_io(slot_idx, gen)`, the slot enters `cancelling_quarantine` and `awaiting_task_id` clears to `0xFFFF_FFFF`. Instead of completing synchronously, `SimReactor` schedules the terminal CQE `1..500 µs` later in virtual time and uses `SimPrng` to split outcomes: half return `-ECANCELED`, and half simulate the real Linux `io_uring` race where an `accept` or `openat` SQE committed a live file descriptor (`cqe.result = sim_fd >= 0`) just before asynchronous cancellation took effect. Upon reaping a `cancelling_quarantine` CQE with `result >= 0`, `SimReactor` executes `slot.gen_state_reaper.reaper` (`close_fd` -> closes `sim_fd`; `release_io_buf` -> frees `pinned_buf`). At `SimWorld` teardown, any unclosed `sim_fd`, un-reaped `cancelling_quarantine` slot, or leaked `IoBuf` fails the test with **`E_SIM_LINEAR_LEAK`**.

### 2.5 Exhaustive Iterative OOM (`FailingAllocator`) and Swarm Fault Injection

`SimFaultAllocator` unifies **Zig's `checkAllAllocationFailures` (`FailingAllocator`)** with **TigerBeetle VOPR and Moonpool's Swarm fault model**:

In **Exhaustive Sequential `OOM` Mode (`--sim-oom=exhaustive`, default for unit `--sim` tests)**, `SimWorld` first executes a calibration pass (`Pass 0`) with `deterministic_fail_idx = u64::MAX`, recording the total allocation count `N_alloc` and storing prefix `ExecutionDigest` checkpoints `D[0 .. N_alloc]` before each `alloc` or growing `realloc` call. It then re-runs the test `N_alloc` times from the identical seed, setting `deterministic_fail_idx = i` for `i` from `0` to `N_alloc - 1` so every single dynamic allocation point systematically returns `.Err(AllocError::OutOfMemory)`. Backed by a shadow allocation map recording `(Layout, alloc_seq_idx, ErrorReturnTrace)` per live pointer, `SimFaultAllocator` verifies after every iteration that `live_blocks == 0`, catching missing `errdefer` cleanups, double frees, and layout-size mismatches on error-unwind paths and printing both the failing allocation's stack trace and the leaked allocation's origin trace. Crucially, whereas Zig's `checkAllAllocationFailures` returns `error.NondeterministicMemoryUsage` whenever code legitimately catches and recovers from `OutOfMemory`, CoreX avoids this false positive by asserting prefix digest equality (`run_i.digest_before(i) == D[i]`): genuine nondeterminism prior to allocation `i` triggers `E_SIM_NONDETERMINISM`, while graceful `OutOfMemory` recovery passes cleanly provided zero bytes leak and test postconditions hold!

In **Swarm Multi-Fault & VOPR Liveness Mode**, each multi-seed `--sim` iteration samples a random per-seed **`SwarmFaultMask`** enabling a subset of fault classes (`has_random_oom`, `has_partial_rw` slicing stream reads/writes to `1..len` bytes, `has_transient_io_err` returning `TimedOut`/`ConnectionReset`/`WouldBlock`, `has_storage_io_err` injecting `EIO`/`ENOSPC` and discarding un-`sync_data` writes on simulated crash, `has_io_reorder_delay` delaying/permuting disk and socket completions across `1..10` virtual ticks, `has_wall_clock_skew`, and `is_buggify_enabled`). For `@test(sim_liveness = true)` targets (and Phase 13.3 multi-node `SimCluster` tests), `SimWorld` implements TigerBeetle VOPR's two-phase **Safety-to-Liveness transition**: after executing 70% of the step budget under Swarm chaos, `SimWorld` sets `is_liveness_frozen = true`, halting transient `OOM` and core I/O error injection while permanently freezing any non-quorum asymmetric partition, and asserts that all active tasks complete within the remaining virtual-time window.

```rust
// File: std/test/sim.cx
mod sim;

use core::context::Context;
use std::mem::{Allocator, Layout, AllocError};
use std::io::ReactorCqe;
use std::col::Map;

/// SplitMix64 seed expander -> Xoshiro256** single-stream deterministic PRNG.
pub struct SimPrng {
    state: [u64; 4],
    pub draw_count: u64,
}

impl SimPrng {
    /// Expands a 64-bit master seed into 256 bits of non-zero `Xoshiro256**` state.
    pub fn from_seed(seed: u64) -> Self {
        var mixed_seed = seed;
        var state: [u64; 4] = [0; 4];
        for i in 0..4 {
            mixed_seed +%= 0x9E37_79B9_7F4A_7C15;
            var word = mixed_seed;
            word = (word ^ (word >> 30)) *% 0xBF58_476D_1CE4_E5B9;
            word = (word ^ (word >> 27)) *% 0x94D0_49BB_1331_11EB;
            state[i] = word ^ (word >> 31);
        }
        SimPrng { state, draw_count: 0 }
    }

    /// Draws the next deterministic 64-bit pseudorandom word.
    @inline
    pub fn next_u64(&mut self) -> u64 {
        self.draw_count +%= 1;
        let result = ((self.state[1] *% 5).rotate_left(7)) *% 9;
        let shifted = self.state[1] << 17;
        self.state[2] ^= self.state[0];
        self.state[3] ^= self.state[1];
        self.state[1] ^= self.state[2];
        self.state[0] ^= self.state[3];
        self.state[2] ^= shifted;
        self.state[3] = self.state[3].rotate_left(45);
        result
    }

    /// Evaluates a parts-per-million fault probability draw (`0 ..= 1_000_000`).
    @inline
    pub fn hit_ppm(&mut self, prob_ppm: u32) -> bool {
        if prob_ppm == 0 { return false; }
        ((self.next_u64() % 1_000_000) as u32) < prob_ppm
    }
}

/// 32-byte discrete-event wheel entry ordered by `(deadline_ns, tie_order)`.
@repr(C)
@derive(Copy)
pub struct SimEvent {
    pub deadline_ns: u64,
    pub tie_order: u64,
    pub cqe: ReactorCqe,
}

/// Per-seed Swarm fault-injection configuration bitmask.
pub type SwarmFaultMask = bit_field u16 {
    pub has_random_oom:       bool | 1,
    pub has_partial_rw:       bool | 1,
    pub has_transient_io_err: bool | 1,
    pub has_storage_io_err:   bool | 1,
    pub has_io_reorder_delay: bool | 1,
    pub has_cancel_win_race:  bool | 1,
    pub has_wall_clock_skew:  bool | 1,
    pub is_buggify_enabled:   bool | 1,
    pub is_liveness_frozen:   bool | 1,
    pub reserved:             u8   | 7,
};

/// Shadow metadata recorded per live allocation in `SimFaultAllocator`.
pub struct AllocationRecord {
    pub layout: Layout,
    pub alloc_seq_idx: u64,
    pub caller_pc: usize,
}

/// Deterministic sequential/Swarm OOM fault-injecting and leak-tracking allocator.
pub struct SimFaultAllocator {
    pub backing: *mut dyn Allocator,
    pub alloc_seq: u64,
    pub deterministic_fail_idx: u64,
    pub random_oom_ppm: u32,
    pub live_blocks: Map[usize, AllocationRecord],
    pub live_bytes: usize,
    pub world: *mut SimWorld,
}

impl Allocator for SimFaultAllocator {
    fn alloc(&mut self, layout: Layout) -> Result[*mut u8, AllocError] {
        let cur_idx = self.alloc_seq;
        self.alloc_seq += 1;
        unsafe { (*self.world).fold_digest(0xA110C, cur_idx, layout.size as u64); }

        if cur_idx == self.deterministic_fail_idx {
            return .Err(.OutOfMemory);
        }
        unsafe {
            let world = &mut *self.world;
            if world.fault_mask.has_random_oom and not world.fault_mask.is_liveness_frozen {
                if world.prng.hit_ppm(self.random_oom_ppm) {
                    return .Err(.OutOfMemory);
                }
            }
        }

        let ptr = self.backing.alloc(layout)?;
        self.live_blocks.insert(ptr as usize, AllocationRecord {
            layout,
            alloc_seq_idx: cur_idx,
            caller_pc: @return_address(),
        });
        self.live_bytes += layout.size;
        .Ok(ptr)
    }

    fn realloc(&mut self, ptr: *mut u8, old: Layout, new_size: usize) -> Result[*mut u8, AllocError] {
        if new_size > old.size {
            let new_layout = Layout { size: new_size, alignment: old.alignment };
            let new_ptr = self.alloc(new_layout)?;
            unsafe { std::mem::copy_nonoverlapping(ptr, new_ptr, old.size); }
            self.dealloc(ptr, old);
            return .Ok(new_ptr);
        }
        .Ok(ptr)
    }

    fn dealloc(&mut self, ptr: *mut u8, layout: Layout) {
        let addr = ptr as usize;
        let rec = self.live_blocks.remove(&addr).unwrap_or_else(|| {
            panic("E_SIM_DOUBLE_OR_INVALID_FREE: ptr=0x{addr:x}");
        });
        if rec.layout != layout {
            panic("E_SIM_LAYOUT_MISMATCH: expected {rec.layout.size}B, got {layout.size}B");
        }
        self.live_bytes -= layout.size;
        self.backing.dealloc(ptr, layout);
    }
}

CoreX resolves two documented toolchain pitfalls across platforms:

First, while Clang's documentation warns that `-fsanitize-coverage=pc-table` can conflict with `-Wl,-gc-sections` on non-LLD linkers, CoreX links exclusively via embedded `lld::lldMain` (`DR-09`): on **Linux ELF**, `lld::elf::link` honors `SHF_LINK_ORDER` and zero-flag COMDAT groups so dead-stripped functions discard their counter and PC entry as an atomic unit; on **macOS Mach-O**, `lld::macho::link` preserves parallel `__DATA,__sancov_cntrs` and `__DATA,__sancov_pcs` slices; and on **Windows PE/COFF**, LLVM emits `.SCOV$CM` and `.SCOVP$M` subsections with `align(1)` on `sancov_cntrs` so COFF section merging inserts zero alignment padding bytes between `__start___sancov_cntrs` and `__stop___sancov_cntrs`. During `--fuzz` builds, `corex` passes `--icf=none` to `lld` (overriding `DR-20` `D-11`'s `--icf=safe`) so distinct generic instantiations retain separate coverage counters and never trigger counter/PC length mismatches.

#### 3. Phase 13.0 Tier-C (`--dev`) Direct Branchless Saturating 8-Bit Counters

In Phase 13.0 (`corex test --fuzz --dev`), `src/compiler/direct_emitter.cx` (`DR-09` §2.1) assigns each `MirTerminator` outgoing edge a 1-byte slot in a writable `.sancov_dev_cntrs` atom (patched in place alongside `.text` via `padToIdeal` slack). Naive wrapping 8-bit increments (`inc byte [rip + disp]`) wrap `255 -> 0` on the 256th loop iteration, erasing covered edges from the bitmap. Tier C therefore emits a **branchless sticky-saturating 8-bit increment** (`min(255, cntr + 1)`) at each edge transition:
-   **`x86_64` (4 instructions, 0 branches):** `movzx r11d, byte ptr [rip + disp32]`; `cmp r11b, 255` (sets `CF = 1` iff `r11b < 255`, `CF = 0` when `r11b == 255`); `adc r11b, 0`; `mov byte ptr [rip + disp32], r11b`.

-   **`wasm32` (branchless Wasm MVP):** `i32.const <addr>`; `i32.const <addr>`; `i32.load8_u`; `local.tee $tmp`; `i32.const 255`; `i32.lt_u`; `i32.add`; `i32.store8`.

### 3.3 In-Process Coverage-Guided Mutation Engine and Crash/Hang Isolation

After every target execution, `FuzzWorker` sweeps `sancov_cntrs` in 32-byte `Simd[u8, 32]` chunks. Because most executions touch a small fraction of total program edges, testing `(chunk != Simd::splat(0))` skips 32 zero counters in one vector comparison. Non-zero bytes `1..=255` are mapped through AFL/LibAFL's 9-class logarithmic bucket lookup table `COUNT_CLASS_LUT[256]`:

$$\text{Bucket}(c) = \begin{cases} 0 & c = 0 \\ 1 & c = 1 \\ 2 & c = 2 \\ 4 & c = 3 \\ 8 & 4 \le c \le 7 \\ 16 & 8 \le c \le 15 \\ 32 & 16 \le c \le 31 \\ 64 & 32 \le c \le 127 \\ 128 & 128 \le c \le 255 \end{cases}$$

Comparing `COUNT_CLASS_LUT[cntr]` against a persistent 1-byte-per-edge `virgin_bucket_mask: Vec[u8]` (initialized to `0xFF`) detects both newly reached CFG edges and new loop-trip multiplicity classes. Inputs clearing any bit in `virgin_bucket_mask` are retained in `CorpusQueue`, scheduled with priority weighted by recency of discovery (75%) and rare-edge / speed score (25%).

To mutate a scheduled parent buffer, `FuzzWorker` stacks `1..=8` operators drawn from `SimPrng`: bit/byte flips, boundary integer replacements (`0`, `1`, `i8::MIN`, `u16::MAX`, `i32::MIN`, `u64::MAX`), little/big-endian `±1..35` arithmetic deltas, `.rodata` string dictionary token insertions, cross-corpus splicing, and **Input-to-State (`I2S`) `TORC` replacement**. `TORC` comprises two L1-cache-resident ring buffers totaling **16 KiB**: `TORC4` (`1,024` × `8 B` entries `{ lhs: u32, rhs: u32 }`) and `TORC8` (`512` × `16 B` entries `{ lhs: u64, rhs: u64 }`), indexed by `(caller_pc ^ (lhs ^ rhs))`. Because LLVM's `__sanitizer_cov_trace_const_cmp*` places the compile-time constant in `arg1` and the input-derived runtime value in `arg2`, `FuzzWorker` scans the parent input for `arg2` (both native and byte-swapped) and replaces matching spans with `arg1` (and `arg1 ± 1` for relational `<`/`<=` predicates), solving 32-bit and 64-bit magic headers, tags, and `switch` cases without SMT solver overhead.

For **Zero-Fork Fast Execution + Crash/Timeout Isolation**, `FuzzWorker` binds a 256 KiB per-iteration `BumpArena` (`let cp = iter_arena.checkpoint();`) to `context.allocator` and wraps each target invocation in a thread-local panic recovery jump (`sigsetjmp(…, 0)`). Safe `.cx` panics, SAST residual bounds/overflow traps, and `assert_eq` failures unwind directly to the in-process loop and rewind `iter_arena.restore(cp)` in `O(1)` time without `fork()` overhead. Meanwhile, mirroring Go's `internal/fuzz` coordinator-worker model, the `corex test --fuzz` coordinator supervises `--jobs N` worker processes over shared memory containing a **128-byte `@cache_aligned` `FuzzShmHeader`** (`magic`, `worker_state`, `iter_count`, `start_ns`, `input_len`, `covered_edges`, `panic_pc`) followed by the active `input_bytes[0 .. max_len]` flushed prior to each call. If `unsafe` / C FFI code triggers `SIGSEGV`/`SIGBUS`/`SIGABRT` (caught on `sigaltstack`) or hangs past `--fuzz-timeout` (`1,000 ms` default), the coordinator extracts the exact offending `input_bytes[0 .. input_len]` from shared memory, spawns a clean reducer worker, shrinks the counterexample, and saves the `.cxfuzz` regression file!

### 3.4 Structure-Aware ChoiceCursor Generator and Shortlex Shrinker (`@derive(Arbitrary)`)

Type-directed recursive `shrink(&self)` traits break down when types uphold constructor invariants or transform parsed fields, whereas mutating and shrinking raw unstructured bytestrings fails on floats, signed integers, and variable-length lists due to non-injective encodings and byte-shift misalignment. CoreX unifies **Rust `arbitrary`'s zero-copy byte cursor** with **MacIver & Donaldson's Hypothesis Conjecture shortlex reducer (ECOOP 2020)** and **typed choice-span boundaries (`hypothesis#3921`)**.

Under **Shortlex Ordering**, choice buffer $s$ is strictly simpler than $t$ ($s <_{\text{shortlex}} t$) iff:

$$|s| < |t| \;\lor\; \bigl(|s| = |t| \land \exists j < |s|.\; (\forall i < j.\; s[i] = t[i]) \land s[j] < t[j]\bigr)$$

To ensure shortlex byte minimization aligns monotonically with domain simplicity (`0x00` === simplest value), `ChoiceCursor` defines five canonical encodings:
1.  **Booleans (`draw_bool`):** Reads 1 byte; `(byte_val & 1) != 0` (`0x00 -> false`, `0x01 -> true`).
2.  **Unsigned & `DR-04` Range-Refined Integers (`draw_uint_range(min, max)`):** Reads the minimum byte width (`1`, `2`, `4`, or `8` bytes) covering `max - min` and maps `0x00..00` to `0` (if `min <= 0 <= max`) or `min`, scaling into `[min, max]` without rejection loops so `u16 is 1..=1024` refinements always construct valid values.
3.  **Signed Integers (`draw_int_zigzag`):** Decodes unsigned $u$ via **Zig-Zag Simplicity Mapping** (`0 -> 0`, `1 -> 1`, `2 -> -1`, `3 -> 2`, `4 -> -2`), placing small positive and negative magnitudes adjacent to `0x00`.
4.  **IEEE-754 Floats (`draw_f64`):** Resolves bytestring float-shrinking pathologies via a 1-to-9-byte simplicity tag: `0x00` -> `0.0`; `0x01..=0x7F` -> exact small integers `±1.0 .. ±63.0`; `0x80..=0xFD` -> simple dyadic fractions `m / 2^k` (`0.5`, `0.25`, …); `0xFE` -> 8-byte finite mantissa/exponent; `0xFF` -> boundary specials (`-0.0`, `±Inf`, canonical `NaN`). Lowering the tag byte smoothly reduces `NaN -> 3.14159265 -> 3.5 -> 3.0 -> 1.0 -> 0.0`!
5.  **Span-Delimited Collections (`draw_vec[T]`):** Instead of reading a front `len` integer (where deleting an element shifts every subsequent field's byte alignment!), `draw_vec` reads a 1-byte continuation flag per element: `0x00` ends the vector (`[]`), while `flag != 0x00` opens a `ChoiceKind::ListElem` span and parses `T::arbitrary(cursor)`. Splicing out `[elem.start_off .. elem.end_off)` deletes an arbitrary element while leaving all later vector elements and sibling struct fields 100% byte-aligned!

During fuzzing (`is_recording_spans == false`), `ChoiceCursor` slices directly over `raw: &[u8]` (returning `0x00` past `raw.len()`) with **zero heap allocations**. Only when a crash or assertion failure is caught does `ShrinkEngine` re-parse the input once with `is_recording_spans = true` to capture a flat tree of **12-byte `ChoiceSpan`** nodes (`{ start_off: u32, end_off: u32, parent_idx: u16, kind: ChoiceKind, type_hash_lo: u8 }`). Adapting Conjecture's five reduction pass categories, `ShrinkEngine` iterates to a shortlex fixpoint (accepting any candidate reproducing the identical `(FailureKind, panic_file_id, panic_line)` signature within `--fuzz-shrink-time`, default `5s`):
1.  **Pass 1 – Contiguous Span Deletion (`ddmin`):** Deletes `ListElem` chunks of decreasing granularity (`M/2, M/4, …, 1`) in `O(M log M)` checks.
2.  **Pass 2 – Recursive Sub-Region Replacement:** Replaces any `Group` span with a nested child `Group` span sharing the same `type_hash_lo` (e.g., hoisting leaf `Expr` out of `Expr::Add(lhs, rhs)`).
3.  **Pass 3 – Zeroed Span Replacement:** Zero-fills entire `Group`, `Str`, and `Bytes` spans (`memset(0)`), collapsing unused struct sub-trees to canonical defaults in one step.
4.  **Pass 4 – Typed Lexicographic Binary Search:** Binary-searches `Int` spans toward `0`, steps `Float` simplicity tags downward, and simplifies UTF-8 `Str` bytes toward `'0'`/`'a'`.
5.  **Pass 5 – Coupled Deletion + Lexicographic Adjustment:** Simultaneously trims `k` bytes from a `Bytes`/`ListElem` span while subtracting `k` from a preceding `Int` span, preserving length-header invariants (`hdr.len == payload.len()`) during minimization.

```rust
// File: std/test/arbitrary.cx
mod arbitrary;

use std::meta;
use std::col::Vec;

/// Structural category tag for recorded `ChoiceSpan` nodes during shrinking.
@repr(u8)
@derive(Copy, Equatable)
pub enum ChoiceKind {
    Group = 0, ListElem = 1, Bool = 2, Int = 3, Float = 4, Bytes = 5, Str = 6, EnumVariant = 7,
}

/// 12-byte structural choice node recorded ONLY during post-crash shrinking.
@repr(C)
@derive(Copy)
pub struct ChoiceSpan {
    pub start_off: u32,
    pub end_off: u32,
    pub parent_idx: u16,
    pub kind: ChoiceKind,
    pub type_hash_lo: u8,
}

/// Zero-allocation byte-stream cursor backing `@derive(Arbitrary)` generation and shrinking.
pub struct ChoiceCursor {
    raw: &[u8],
    pos: usize,
    is_recording_spans: bool,
    active_parent: u16,
    pub spans: Vec[ChoiceSpan],
}

impl ChoiceCursor {
    /// Creates an unrecorded zero-allocation cursor for hot fuzz iterations.
    @no_fuzz_instrument
    pub fn fast(raw: &[u8]) -> Self {
        ChoiceCursor { raw, pos: 0, is_recording_spans: false, active_parent: 0xFFFF, spans: Vec::new() }
    }

    /// Consumes the next choice byte, returning `0x00` (simplest default) past buffer end.
    @inline @no_fuzz_instrument
    pub fn next_byte(&mut self) -> u8 {
        if self.pos < self.raw.len() {
            let byte_val = self.raw[self.pos];
            self.pos += 1;
            byte_val
        } else {
            0
        }
    }

    pub fn draw_bool(&mut self) -> bool;
    pub fn draw_uint_range[T: Unsigned](&mut self, min: T, max: T) -> T;
    pub fn draw_int_zigzag[T: Signed](&mut self, min: T, max: T) -> T;
    pub fn draw_f64(&mut self, is_nan_inf_allowed: bool = true) -> f64;
    pub fn draw_str_utf8(&mut self, max_bytes: usize = 256) -> str;
    pub fn draw_bytes(&mut self, max_bytes: usize = 512) -> &[u8];
    pub fn take_rest(&mut self) -> &[u8];
}

/// Trait implemented by types constructible from a deterministic `ChoiceCursor`.
pub trait Arbitrary {
    fn arbitrary(cursor: &mut ChoiceCursor) -> Self;
}

/// Synthesized automatically at `comptime` via `DR-05` `std::meta` reflection for `@derive(Arbitrary)`.
pub fn derive_arbitrary_struct[T](cursor: &mut ChoiceCursor) -> T {
    let span_tok = cursor.begin_span(.Group, @type_hash_lo[T]());
    var val: T = uninit;
    comptime for field_info in meta::fields_of[T]() {
        @field_mut(&mut val, field_info.name) = meta::draw_field_arbitrary[field_info.Type, field_info.range](cursor);
    }
    cursor.end_span(span_tok);
    val
}
```
